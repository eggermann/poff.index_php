# dodi Current State

This is a short audit note for the live `dodi2` and `dodi` pages.

## What I checked

- `dodi2` currently shows only the base PHP file-browser shell and `index.php`.
- There are no film uploads visible on `dodi2`.
- `dodi` is the eggermann copy tree, not a movie-link workspace.

## What this means

- The earlier movie-link assumption was wrong.
- The current live state is a copy/browser workspace, not a film-upload handoff flow.
- If a film workflow is wanted later, it should be added explicitly instead of inferred from the current pages.
