# Poff File Browser

A single-file PHP file browser built from modular source files in `src/`.
It includes a viewer for common file types, per-folder/per-file config, and MCP
routes for automation helpers like create and workprompt.

## What This App Does

- Browse folders and files with a sidebar tree.
- Render files in a viewer (images, video, audio, text, links, pdf, and other types).
- Store per-folder metadata in `poff.config.json` and per-file metadata in `.works/*.config.json`.
- Expose MCP routes for automation and edit mode.
- Provide an edit mode UI when `?edit=true` and a validation file exists.

## Project Layout

- `src/` - Source files (edit here).
  - `src/includes/` - Header, layout, scripts, viewer, and config helpers.
  - `src/assets/` - Modular JS/SCSS sources for the bundled inline assets.
  - `src/mcp/` - MCP server + route handlers.
- `build/` - Build pipeline that concatenates `src` into a single `index.php`.
- `pages/` - Generated output (`pages/dominikeggermann.com/index.php`).
- `tests/` - MCP create-route tests and test fixtures.

Important: `pages/dominikeggermann.com/index.php` is generated. Do not edit it directly.

## Config Files

### `poff.config.json`
Stored in each folder, generated by `PoffConfig::ensure`.

Key fields:
- `folderName`, `slug`, `title`, `description`
- `tree`: first-level items with `visible` flags
- `work`: per-folder work metadata
  - `work.layout` can be a string or object
  - `work.layout.template` is used by prompt editing

### `.works/{filename}.config.json`
Per-file config, stored next to files inside `.works/`.

### `poff.config.toon`
Written by MCP for workspace tree snapshots (used by MCP info routes).

## Edit Mode (Fake Login)

Edit mode is enabled when:
1) A file named `.edit.allow` exists in the site root, and
2) The URL includes `?edit=true`.

Edit mode UI:
- Inline edits: title + description (in-place, with Save).
- "More..." drawer: link, url, work type, work layout, tree visibility.
- Prompt window: generates and saves `work.layout.template`.

Edits are saved through same-page edit endpoints (`?edit=config`, `?edit=save`, `?edit=prompt`).

## Prompt Window (Template Generation)

Providers:
- `local` (custom HTTP endpoint)
- `openai`
- `gemini`

API key sources:
- `.env` (`OPENAI_API_KEY`, `GEMINI_API_KEY`)
- or browser localStorage (set in the edit UI)

Local endpoint payload:
```json
{
  "prompt": "string",
  "history": [{ "role": "user|assistant", "content": "..." }],
  "config": { ...full poff.config.json... },
  "instruction": "string"
}
```

Expected local response:
- JSON with `{ "template": "..." }`, or
- a plain text body (used as template).

Templates are saved into `work.layout.template` via the same-page edit endpoint.

## MCP Routes

The MCP server lives at `src/mcp/server.php` and can be called via:
`index.php?mcp=1&route=...` (when built) or directly at `/src/mcp/server.php`.

Routes:
- `info` (default): returns config + tree info
- `create`: create folders or copy content into a destination
- `workprompt`: prepare a work prompt and template for a file
- `style`: simple echo route for styling prompts
Note: the edit UI does not use MCP. It calls the same page with `?edit=...`.

### MCP Examples

Fetch MCP info:
```sh
curl "http://localhost/your-index.php?mcp=1"
```

Create a destination folder under `poff`:
```sh
curl "http://localhost/your-index.php?mcp=1&route=create&dest=demo-folder"
```

Copy from a path under `/poff`:
```sh
curl "http://localhost/your-index.php?mcp=1&route=create&dest=demo-copy&path=datas"
```

Workprompt for a file:
```sh
curl "http://localhost/your-index.php?mcp=1&route=workprompt&file=folder/file.jpg&style=Bold%20layout"
```

Read folder config via edit-config:
```sh
curl "http://localhost/your-index.php?mcp=1&route=edit-config&path=some-folder"
```

Save config updates:
```sh
curl -X POST "http://localhost/your-index.php?mcp=1&route=edit-config&path=some-folder" \
  -H "Content-Type: application/json" \
  -d '{"title":"New title","description":"Updated","layout":{"mode":"grid","template":"..."},"treeVisible":["index.php"]}'
```

Generate a template via prompt-template (local endpoint):
```sh
curl -X POST "http://localhost/your-index.php?mcp=1&route=prompt-template&path=some-folder" \
  -H "Content-Type: application/json" \
  -d '{"provider":"local","endpoint":"http://localhost:1234/generate","prompt":"Create a card layout"}'
```

## Build Process

Source is compiled into a single PHP file:
- Build script: `build/build.php`
- Config: `build/BuildConfig.php`
- Output: `pages/dominikeggermann.com/index.php`
- Local index copies: `MAUSMAUS`, `node-1`, `node-2`, `pageoff`, and `dominikeggermann-project/page` under MAMP `htdocs`.
  The `dominikeggermann-project/page` target receives only the fresh `index.php`; it does not receive copied layout assets or converter templates.

Asset build dependencies:
```sh
npm install
```

Asset pipeline:
- JS entry: `src/assets/js/app.js`
- SCSS entry: `src/assets/scss/main.scss`
- The builder injects compiled output into `src/includes/header.built.php` and `src/includes/scripts.built.php` (see `POFF_STYLE_*` and `POFF_SCRIPT_*` blocks).

Manual build:
```sh
npm run build
```

If you only want to rebuild assets:
```sh
npm run build:assets
```

Manual (two-step) build:
```sh
node scripts/build-assets.js
php build/build.php
```

Equivalent npm commands:
```sh
npm run build:assets
npm run build:php
```

Auto build:
- The watcher script is `scripts/watch-build.js`.
- If your `package.json` includes the watch script, run `npm run watch`.
- Otherwise run:
```sh
node scripts/watch-build.js
```

The watcher rebuilds on changes (assets + PHP) and optionally refreshes a browser tab when running under MAMP.

#!/usr/bin/env node
const fs = require('fs');
const path = require('path');
const esbuild = require('esbuild');
const sass = require('sass');
const { createGenerator } = require('@unocss/core');

const rootDir = path.resolve(__dirname, '..');
const jsEntry = path.join(rootDir, 'src', 'assets', 'js', 'app.js');
const scssEntry = path.join(rootDir, 'src', 'assets', 'scss', 'main.scss');
const headerPath = path.join(rootDir, 'src', 'includes', 'header.built.php');
const scriptsPath = path.join(rootDir, 'src', 'includes', 'scripts.built.php');
const distDir = path.join(rootDir, 'build', 'assets');
const unoConfig = require(path.join(rootDir, 'uno.config.js'));
const srcDir = path.join(rootDir, 'src');
const contentExtensions = new Set(['.php', '.js', '.hbs']);
const buildMode = process.env.POFF_BUILD_MODE === 'production' ? 'production' : 'development';
const isProductionBuild = buildMode === 'production';

function replaceBetween(content, startMarker, endMarker, replacement) {
  const startIndex = content.indexOf(startMarker);
  if (startIndex === -1) {
    throw new Error(`Missing start marker: ${startMarker}`);
  }
  const endIndex = content.indexOf(endMarker, startIndex + startMarker.length);
  if (endIndex === -1) {
    throw new Error(`Missing end marker: ${endMarker}`);
  }
  const before = content.slice(0, startIndex + startMarker.length);
  const after = content.slice(endIndex);
  return `${before}\n${replacement}\n${after}`;
}

function buildJs() {
  const result = esbuild.buildSync({
    entryPoints: [jsEntry],
    bundle: true,
    write: false,
    format: 'iife',
    platform: 'browser',
    target: ['es2018'],
    sourcemap: false,
    minify: isProductionBuild,
  });
  return result.outputFiles[0].text;
}

function collectContentFiles(dir) {
  const entries = fs.readdirSync(dir, { withFileTypes: true });
  const files = [];
  for (const entry of entries) {
    const fullPath = path.join(dir, entry.name);
    if (entry.isDirectory()) {
      files.push(...collectContentFiles(fullPath));
      continue;
    }
    if (!entry.isFile()) {
      continue;
    }
    if (!contentExtensions.has(path.extname(entry.name))) {
      continue;
    }
    if (fullPath === headerPath || fullPath === scriptsPath) {
      continue;
    }
    files.push(fullPath);
  }
  return files;
}

async function buildCss() {
  const uno = createGenerator(unoConfig);
  const files = collectContentFiles(srcDir);
  const contents = files.map((file) => fs.readFileSync(file, 'utf8')).join('\n');
  const { css: unoCss } = await uno.generate(contents, { preflights: true });
  const scssCss = sass.compile(scssEntry, {
    style: isProductionBuild ? 'compressed' : 'expanded',
    loadPaths: [path.dirname(scssEntry)],
  }).css;
  return [unoCss.trim(), scssCss.trim()].filter(Boolean).join('\n\n').trim();
}

function writeIfChanged(targetPath, nextContent) {
  const current = fs.existsSync(targetPath) ? fs.readFileSync(targetPath, 'utf8') : null;
  if (current === nextContent) {
    return false;
  }
  fs.writeFileSync(targetPath, nextContent);
  return true;
}

function writeDist(js, css) {
  fs.mkdirSync(distDir, { recursive: true });
  writeIfChanged(path.join(distDir, 'app.js'), js);
  writeIfChanged(path.join(distDir, 'app.css'), css);
}

function updateHeader(css) {
  const header = fs.readFileSync(headerPath, 'utf8');
  const trimmed = css.trim();
  const updated = replaceBetween(header, '/* POFF_STYLE_START */', '/* POFF_STYLE_END */', trimmed);
  writeIfChanged(headerPath, updated);
}

function updateScripts(js) {
  const scripts = fs.readFileSync(scriptsPath, 'utf8');
  const safeJs = js.replace(/<\/script>/gi, '<\\/script>');
  const trimmed = safeJs.trim();
  const updated = replaceBetween(scripts, '/* POFF_SCRIPT_START */', '/* POFF_SCRIPT_END */', trimmed);
  writeIfChanged(scriptsPath, updated);
}

async function runBuild() {
  const js = buildJs();
  const css = await buildCss();
  writeDist(js, css);
  updateHeader(css);
  updateScripts(js);
  console.log(`[assets] Built CSS/JS (${buildMode}) and updated header/scripts placeholders.`);
}

runBuild().catch((err) => {
  console.error(`[assets] ${err.message}`);
  process.exit(1);
});

#!/usr/bin/env node
const fs = require('fs');
const path = require('path');
const { spawn, spawnSync } = require('child_process');

const rootDir = path.resolve(__dirname, '..');
const defaultMampPort = 8888; // default MAMP port; adjust here if needed

function logBrowseUrl(linkName) {
  if (!linkName) return;
  const url = `http://localhost:${defaultMampPort}/${linkName}/`;
  console.log(`[watch] Open in browser: ${url}`);
}

function readBuildConfig() {
  const result = spawnSync('php', [path.join(rootDir, 'build', 'export-config.php')], {
    encoding: 'utf8',
    cwd: rootDir,
  });

  if (result.status !== 0) {
    const stderr = result.stderr ? result.stderr.trim() : 'unknown error';
    throw new Error(`Could not read build config: ${stderr}`);
  }

  try {
    return JSON.parse(result.stdout);
  } catch (err) {
    throw new Error(`Failed to parse build config JSON: ${err.message}`);
  }
}

function ensureSymlink(outputDir, config) {
  if (!config.mampHtdocs) {
    console.warn('[watch] MAMP htdocs is not configured, skipping symlink.');
    return null;
  }
  const resolvedOutput = path.resolve(outputDir);
  const resolvedHtdocs = path.resolve(config.mampHtdocs);
  const linkName = path.basename(resolvedOutput);

  if (!fs.existsSync(resolvedHtdocs)) {
    console.warn(`[watch] MAMP htdocs not found at ${resolvedHtdocs}, skipping symlink.`);
    return null;
  }

  if (resolvedOutput.startsWith(resolvedHtdocs)) {
    console.log(`[watch] Output already inside ${resolvedHtdocs}, no symlink needed.`);
    logBrowseUrl(path.relative(resolvedHtdocs, resolvedOutput).split(path.sep)[0]);
    return null;
  }

  const linkPath = path.join(resolvedHtdocs, linkName);

  if (fs.existsSync(linkPath)) {
    const stat = fs.lstatSync(linkPath);

    if (!stat.isSymbolicLink()) {
      console.warn(`[watch] ${linkPath} exists and is not a symlink; leaving it alone.`);
      return linkName;
    }

    const currentTarget = path.resolve(path.dirname(linkPath), fs.readlinkSync(linkPath));
    if (currentTarget === resolvedOutput) {
      console.log(`[watch] Symlink already points to ${resolvedOutput}.`);
      logBrowseUrl(linkName);
      return linkName;
    }

    fs.unlinkSync(linkPath);
  }

  fs.symlinkSync(resolvedOutput, linkPath);
  console.log(`[watch] Created symlink ${linkPath} -> ${resolvedOutput}.`);
  logBrowseUrl(linkName);
  return linkName;
}

function refreshBrowser() {
  const scripts = [
    'tell application "Google Chrome" to if exists window 1 then tell the active tab of window 1 to reload',
    'tell application "Safari" to if exists document 1 then tell document 1 to do JavaScript "window.location.reload()"',
  ];

  scripts.forEach((script) => {
    const result = spawnSync('osascript', ['-e', script], { stdio: 'ignore' });
    if (result.status === 0) {
      console.log('[watch] Browser refresh requested.');
    }
  });
}

function startWatcher() {
  const config = readBuildConfig();
  const sourceDir = path.resolve(config.sourceDir);

  if (!fs.existsSync(sourceDir)) {
    throw new Error(`Source directory not found: ${sourceDir}`);
  }

  let debounceTimer = null;
  let building = false;
  let rerun = false;

  const queueBuild = (reason) => {
    if (debounceTimer) {
      clearTimeout(debounceTimer);
    }
    debounceTimer = setTimeout(() => runBuild(reason), 150);
  };

  const runBuild = (reason) => {
    if (building) {
      rerun = true;
      return;
    }

    building = true;
    console.log(`[watch] Running build (${reason || 'change'})...`);

    const proc = spawn('npm', ['run', 'build'], {
      cwd: rootDir,
      stdio: 'inherit',
    });

    proc.on('exit', (code) => {
      building = false;

      if (code === 0) {
        try {
          const freshConfig = readBuildConfig();
          ensureSymlink(freshConfig.outputDir, freshConfig);
          refreshBrowser();
        } catch (err) {
          console.error(`[watch] Post-build step failed: ${err.message}`);
        }
      } else {
        console.error(`[watch] Build failed with exit code ${code}.`);
      }

      if (rerun) {
        rerun = false;
        runBuild('queued change');
      }
    });
  };

  try {
    const ignoredFiles = new Set(['includes/header.built.php', 'includes/scripts.built.php']);
    fs.watch(sourceDir, { recursive: true }, (_event, fileName) => {
      const normalized = fileName ? fileName.replace(/\\/g, '/') : '';
      if (normalized && ignoredFiles.has(normalized)) {
        return;
      }
      const label = fileName ? `${fileName.trim() || 'unknown file'}` : 'unknown file';
      queueBuild(`change in ${label}`);
    });
  } catch (err) {
    throw new Error(`Failed to start watcher: ${err.message}`);
  }

  console.log(`[watch] Watching ${sourceDir} for changes...`);
  runBuild('startup');
}

try {
  startWatcher();
} catch (err) {
  console.error(`[watch] ${err.message}`);
  process.exit(1);
}

    public static function render(string $kind, array $ctx): string

        if ($fallbackRendered !== null) {
            return $fallbackRendered;

        return self::fallbackRender($kind, $ctx);

    private static function helpers(): array
    {
        return [
            'eq' => static function ($left = null, $right = null, $options = null): bool {
                return $left == $right;
            },
            'ne' => static function ($left = null, $right = null, $options = null): bool {
                return $left != $right;
            },
            'contains' => static function ($haystack = null, $needle = null, $options = null): bool {
                if ($needle === null) {
                    return false;
                }
                if (is_array($haystack)) {
                    return in_array($needle, $haystack, false);
                }

                return str_contains((string) $haystack, (string) $needle);
            },
            'startsWith' => static function ($value = null, $prefix = null, $options = null): bool {
                if ($prefix === null) {
                    return false;
                }

                return str_starts_with((string) $value, (string) $prefix);
            },
            'endsWith' => static function ($value = null, $suffix = null, $options = null): bool {
                if ($suffix === null) {
                    return false;
                }

                return str_ends_with((string) $value, (string) $suffix);
            },
            'not' => static function ($value = null, $options = null): bool {
                return !$value;
            },
            'and' => static function ($left = null, $right = null, $options = null): bool {
                return (bool) $left && (bool) $right;
            },
            'or' => static function ($left = null, $right = null, $options = null): bool {
                return (bool) $left || (bool) $right;
            },

    private static function renderTemplate(string $kind, array $ctx, array $work, array $layout): ?string
    {
        $template = self::layoutTemplate($kind, $work);
        if ($template === '' || !self::rendererAvailable()) {
            return null;
        }

        $partials = self::sanitizePartials(self::templates());
        $section = (string) ($layout['section'] ?? ($kind === 'folder' ? 'works' : 'work'));
        if (!empty($layout['sectionTemplate']) && is_string($layout['sectionTemplate'])) {
            $partials[$section] = $layout['sectionTemplate'];
            $template = self::ensureTemplateIncludesSectionPartial($template, $section, $layout);
        }

        $handlerInstalled = false;
        try {
            set_error_handler(
                static function (int $severity, string $message, string $file = '', int $line = 0): void {
                    throw new \ErrorException($message, 0, $severity, $file, $line);
                }
            );
            $handlerInstalled = true;
            $compiled = \LightnCandy\LightnCandy::compile($template, [
                'partials' => $partials,
                'helpers' => self::helpers(),
                'flags' => \LightnCandy\LightnCandy::FLAG_HANDLEBARSJS
                    | \LightnCandy\LightnCandy::FLAG_RUNTIMEPARTIAL
                    | \LightnCandy\LightnCandy::FLAG_ERROR_LOG,
            ]);
            if (!is_string($compiled) || $compiled === '') {
                return null;
            }
            $renderer = \LightnCandy\LightnCandy::prepare($compiled);
            if (!is_callable($renderer)) {
                return null;
            }

            $rendered = $renderer(self::buildRenderContext($kind, $ctx, $work, $layout));
            return is_string($rendered) ? self::normalizeRenderedViewerUrls($rendered) : null;
        } catch (\Throwable $error) {
            return null;
        } finally {
            if ($handlerInstalled) {
                restore_error_handler();
            }
        }
    }

    private static function normalizeRenderedViewerUrls(string $html): string
    {
        return preg_replace_callback(
            '/\b(href|src)=([\'"])(.*?)\2/i',
            static function (array $matches): string {
                $value = html_entity_decode((string) $matches[3], ENT_QUOTES | ENT_HTML5, 'UTF-8');
                if (substr_count($value, '?view=1&') < 2) {
                    return $matches[0];
                }

                $lastQueryStart = strrpos($value, '?view=1&');
                if ($lastQueryStart === false) {
                    return $matches[0];
                }

                $normalized = substr($value, $lastQueryStart);
                $escaped = htmlspecialchars($normalized, ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8');
                return $matches[1] . '=' . $matches[2] . $escaped . $matches[2];
            },
            $html
        ) ?? $html;
    }

    private static function ensureTemplateIncludesSectionPartial(string $template, string $section, array $layout): string
    {
        if (strpos($template, '{{#if isFolder}}') !== false && strpos($template, '{{else}}') !== false) {
            return $template;
        }

        $hasWorks = preg_match('/\{\{\s*>\s*works\b/', $template) === 1;
        $hasWork = preg_match('/\{\{\s*>\s*work\b/', $template) === 1;
        $sharedBlock = '{{#if isFolder}}{{> works}}{{else}}{{> work}}{{/if}}';

        if ($hasWorks && !$hasWork) {
            $updated = preg_replace('/\{\{\s*>\s*works\b[^}]*\}\}/', $sharedBlock, $template, 1);
            return is_string($updated) ? $updated : $template;
        }

        if ($hasWork && !$hasWorks) {
            $updated = preg_replace('/\{\{\s*>\s*work\b[^}]*\}\}/', $sharedBlock, $template, 1);
            return is_string($updated) ? $updated : $template;
        }

        $partialPattern = '/\{\{\s*>\s*' . preg_quote($section, '/') . '\b/';
        if (preg_match($partialPattern, $template) === 1) {
            return $template;
        }

        $partialMarkup = '{{> ' . $section . '}}';
        foreach (['</main>', '</section>', '</article>', '</div>'] as $closingTag) {
            $position = strripos($template, $closingTag);
            if ($position !== false) {
                return substr($template, 0, $position) . $partialMarkup . substr($template, $position);
            }
        }

        return $template . $partialMarkup;
    }

    private static function fallbackRender(string $kind, array $ctx): string
    {
        if ($kind === 'folder') {
            return '';
        }

        $path = htmlspecialchars((string) ($ctx['path'] ?? ''), ENT_QUOTES, 'UTF-8');
        $name = htmlspecialchars((string) ($ctx['name'] ?? ''), ENT_QUOTES, 'UTF-8');
        $textContent = (string) ($ctx['textContent'] ?? '');

            return '<pre class="min-h-screen w-full overflow-auto whitespace-pre-wrap rounded-md bg-slate-950 p-4 text-sm text-slate-100">'
                . htmlspecialchars($textContent !== '' ? $textContent : $name, ENT_QUOTES, 'UTF-8')
                . '</pre>';
        }

        return '<iframe src="' . $path . '" title="' . $name . '"></iframe>';
    }

    private static function sanitizePartials(array $partials): array

        $sanitized = [];

                if (!is_scalar($template)) {
                    continue;
                }
                $template = (string) $template;
            }

            $sanitized[$partialName] = $template;
        }

        return $sanitized;
    }

function cmsPersistEditorAuthCookie(string $rootDir, bool $allowed): void
{
    if (cmsAuthBypassEnabled() || headers_sent()) {
        return;
    }

    $cookieName = cmsAuthCookieName();
    $cookiePath = cmsAuthCookiePath();
    $entries = cmsAuthCookieEntries();
    $rootKey = cmsAuthSessionKey($rootDir);

    if ($allowed) {
        $config = cmsLoadAuthConfig($rootDir);
        $hash = (string) ($config['passwordHash'] ?? '');
        if ($hash === '') {
            return;
        }

        $entries[$rootKey] = cmsAuthCookieToken($rootDir, $hash);
    } else {
        unset($entries[$rootKey]);
    }

    if ($entries === []) {
        header(sprintf(
            'Set-Cookie: %s=; Expires=%s; Max-Age=0; Path=%s; %sHttpOnly; SameSite=Strict',
            $cookieName,
            gmdate('D, d M Y H:i:s T', time() - 3600),
            $cookiePath,
            !empty($_SERVER['HTTPS']) ? 'Secure; ' : ''
        ), false);
        return;
    }

    $encoded = cmsAuthCookieEncode($entries);
    if ($encoded === '') {
        return;
    }

    header(sprintf(
        'Set-Cookie: %s=%s; Path=%s; %sHttpOnly; SameSite=Strict',
        $cookieName,
        $encoded,
        $cookiePath,
        !empty($_SERVER['HTTPS']) ? 'Secure; ' : ''
    ), false);
}

function cmsLoadAuthConfig(string $rootDir): array
{
    foreach (cmsAuthConfigCandidates($rootDir) as $candidate) {
        if (!is_file($candidate)) {
            continue;
        }

        $loaded = require $candidate;
        $hash = '';

        if (is_string($loaded)) {
            $hash = trim($loaded);
        } elseif (is_array($loaded)) {
            $hash = trim((string) ($loaded['passwordHash'] ?? $loaded['password_hash'] ?? $loaded['hash'] ?? ''));
        }

        return [
            'configured' => $hash !== '',
            'passwordHash' => $hash,
            'path' => $candidate,
        ];
    }

    $defaultPath = cmsAuthConfigCandidates($rootDir)[0] ?? '';
    if ($defaultPath !== '') {
        $hash = password_hash(cmsDefaultAuthPassword(), PASSWORD_DEFAULT);
        if (is_string($hash) && $hash !== '') {
            @file_put_contents($defaultPath, cmsAuthConfigContents($hash));
            if (is_file($defaultPath)) {
                return [
                    'configured' => true,
                    'passwordHash' => $hash,
                    'path' => $defaultPath,
                ];
            }
        }
    }

    return [
        'configured' => false,
        'passwordHash' => '',
        'path' => null,
    ];
}

    $config = cmsLoadAuthConfig($rootDir);

    $path = (string) ($config['path'] ?? '');

    if ($hash === '' || $path === '') {
        return ['ok' => false, 'error' => 'CMS auth is not configured.'];
    }
    if ($currentPassword === '' || !password_verify($currentPassword, $hash)) {
        return ['ok' => false, 'error' => 'Current password is incorrect.'];

    if (trim($newPassword) === '') {
        return ['ok' => false, 'error' => 'New password must not be empty.'];

    if (!is_string($newHash) || $newHash === '') {

    }
    if (!cmsWriteAuthConfig($path, $newHash)) {
        return ['ok' => false, 'error' => 'Failed to write .poff-auth.php.'];
    }

    return ['ok' => true, 'path' => $path];
}

function cmsExternalSubmissionSettings(array $config): array
{
    $source = is_array($config['externalSubmissions'] ?? null) ? $config['externalSubmissions'] : [];
    $whitelist = [];
    foreach (is_array($source['whitelist'] ?? null) ? $source['whitelist'] : [] as $entry) {
        if (!is_scalar($entry)) {
            continue;
        }
        $candidate = trim((string) $entry);
        if ($candidate === '') {
            continue;
        }
        $parts = parse_url(str_contains($candidate, '://') ? $candidate : "https://{$candidate}");
        $host = strtolower(trim((string) (is_array($parts) ? ($parts['host'] ?? '') : '')));
        if ($host !== '' && !in_array($host, $whitelist, true)) {
            $whitelist[] = $host;
        }
    }

    return [
        'enabled' => !empty($source['enabled']),
        'whitelistEnabled' => array_key_exists('whitelistEnabled', $source) ? !empty($source['whitelistEnabled']) : true,
        'whitelist' => $whitelist,
        'maxPending' => min(20, max(1, (int) ($source['maxPending'] ?? 5))),
    ];
}

function cmsIsAllowedExternalPoffLink(string $url): bool
{
    $trimmed = trim($url);
    if ($trimmed === '') {
        return false;
    }

    $parts = parse_url($trimmed);
    if (!is_array($parts)) {
        return false;
    }

    $scheme = strtolower((string) ($parts['scheme'] ?? ''));
    if (!in_array($scheme, ['http', 'https'], true)) {
        return false;
    }

    parse_str((string) ($parts['query'] ?? ''), $query);
    $view = (string) ($query['view'] ?? '');
    $path = trim((string) ($query['path'] ?? ''));
    $file = trim((string) ($query['file'] ?? ''));

    if ($view === '1' && ($path !== '' || $file !== '')) {
        return true;
    }

    $fragment = trim((string) ($parts['fragment'] ?? ''));
    if ($fragment === '') {
        return false;
    }

    $hashPath = trim(preg_replace('/^[!\\/]+/', '', $fragment) ?? '', "/\\ \t\n\r\0\x0B");
    return $hashPath !== '';
}

function cmsNormalizeExternalLinkCategories(mixed $value): array
{
    $source = is_array($value)
        ? $value
        : (is_string($value) ? (preg_split('/\r?\n|,/', $value) ?: []) : []);
    $categories = [];
    foreach ($source as $candidate) {
        if (!is_scalar($candidate)) {
            continue;
        }
        $normalized = strtolower(trim((string) $candidate));
        $normalized = substr($normalized, 0, 24);
        if ($normalized === '' || in_array($normalized, $categories, true)) {
            continue;
        }
        $categories[] = $normalized;
        if (count($categories) >= 12) {
            break;
        }
    }
    return $categories;
}

function cmsNormalizeExternalPoffNode(mixed $value, string $pageUrl): array
{
    if (!is_array($value)) {
        return [];
    }
    $pageHost = strtolower((string) (parse_url($pageUrl, PHP_URL_HOST) ?? ''));
    if ($pageHost === '') {
        return [];
    }

    $node = ['protocol' => 'poff-node/1'];
    foreach (['baseUrl', 'workCatalogUrl', 'converterCatalogUrl'] as $key) {
        $url = trim((string) ($value[$key] ?? ''));
        $scheme = strtolower((string) (parse_url($url, PHP_URL_SCHEME) ?? ''));
        $host = strtolower((string) (parse_url($url, PHP_URL_HOST) ?? ''));
        if (!in_array($scheme, ['http', 'https'], true) || $host !== $pageHost) {
            continue;
        }
        $node[$key] = $url;
    }
    return count($node) > 1 ? $node : [];
}

function cmsCreateLinkEntry(string $targetDir, string $label, string $linkUrl, array $options = []): array
{
    $target = trim($linkUrl);
    if ($target === '') {
        return cmsUploadErrorResult('Enter a link URL.');
    }

    $scheme = strtolower((string) parse_url($target, PHP_URL_SCHEME));
    if (!in_array($scheme, ['http', 'https'], true)) {
        return cmsUploadErrorResult('Link URLs must start with http:// or https://.');
    }

    $pendingApproval = !empty($options['pendingApproval']);
    $externalSettings = is_array($options['externalSubmissionSettings'] ?? null)
        ? $options['externalSubmissionSettings']
        : [];
    if ($pendingApproval && empty($externalSettings['enabled'])) {
        return cmsUploadErrorResult('This node does not accept external work submissions.');
    }
    if ($pendingApproval && !cmsIsAllowedExternalPoffLink($target)) {
        return cmsUploadErrorResult('Only links from another Poff system are allowed. Use a viewer URL with ?view=1&path=..., ?view=1&file=..., or a hash route like #/work-name.');
    }
    if ($pendingApproval && !cmsExternalSubmissionUrlAllowed($target, $externalSettings)) {
        return cmsUploadErrorResult('This Poff node is not on this host\'s external-work whitelist.');
    }

    $baseUrl = cmsNormalizeRemoteBaseUrl($target);

    $dirError = cmsEnsureUploadDirectory($targetDir);
    if ($dirError !== null) {
        return $dirError;
    }

    $config = PoffConfig::ensure($targetDir);
    $tree = is_array($config['tree'] ?? null) ? $config['tree'] : [];
    $categories = cmsNormalizeExternalLinkCategories($options['categories'] ?? []);
    $poffNode = cmsNormalizeExternalPoffNode($options['poffNode'] ?? [], $target);
    $now = date('c');

    if ($pendingApproval) {
        foreach ($tree as &$existingItem) {
            if (
                !is_array($existingItem)
                || empty($existingItem['externalSubmission'])
                || trim((string) ($existingItem['linkUrl'] ?? '')) !== $target
            ) {
                continue;
            }
            $existingItem['title'] = trim($label) !== '' ? trim($label) : (string) ($existingItem['title'] ?? $existingItem['name'] ?? 'Poff node');
            $existingItem['categories'] = $categories;
            $existingItem['work'] = array_merge(
                is_array($existingItem['work'] ?? null) ? $existingItem['work'] : [],
                ['type' => 'link', 'categories' => $categories]
            );
            if ($poffNode !== []) {
                $existingItem['poffNode'] = $poffNode;
            }
            $existingItem['modifiedAt'] = $now;
            $existingName = (string) ($existingItem['name'] ?? 'poff-node');
            $existingPendingApproval = (string) ($existingItem['approvalStatus'] ?? '') !== 'approved';
            unset($existingItem);

            $config['tree'] = $tree;
            $config['treeHash'] = hash('sha256', json_encode($tree));
            $config['updatedAt'] = $now;
            $encoded = json_encode($config, JSON_PRETTY_PRINT | JSON_UNESCAPED_SLASHES);
            if ($encoded === false || file_put_contents(PoffConfig::configPath($targetDir), $encoded) === false) {
                return cmsUploadErrorResult('Failed to update registered Poff node.');
            }
            return cmsUploadStoredResult($existingName, [
                'linkUrl' => $target,
                'baseUrl' => $baseUrl !== '' ? $baseUrl : $target,
                'pendingApproval' => $existingPendingApproval,
                'updatedRegistration' => true,
            ]);
        }
        unset($existingItem);
    }
    if ($pendingApproval && cmsCountPendingExternalLinks($tree) >= cmsPendingExternalLinkLimit($externalSettings)) {
        return cmsUploadErrorResult('Too many external links are waiting for approval in this folder.');
    }

    $baseName = cmsUploadSafeName($label);
    if ($baseName === '') {
        $host = (string) (parse_url($target, PHP_URL_HOST) ?? '');
        $path = (string) (parse_url($target, PHP_URL_PATH) ?? '');
        $baseName = cmsUploadSafeName(trim($host . ' ' . basename($path)));
    }
    if ($baseName === '') {
        $baseName = 'poff-link';
    }

    $existingNames = [];
    foreach ($tree as $item) {
        if (!is_array($item)) {
            continue;
        }
        $name = trim((string) ($item['name'] ?? ''));
        if ($name !== '') {
            $existingNames[$name] = true;
        }
    }

    $name = $baseName;
    $suffix = 2;
    while (isset($existingNames[$name])) {
        $name = $baseName . '-' . $suffix;
        $suffix++;
    }

    $treeItem = [
        'name' => $name,
        'title' => trim($label) !== '' ? trim($label) : $name,
        'slug' => class_exists('PoffConfig') ? PoffConfig::slugify($name) : $name,
        'type' => 'link',
        'kind' => 'link',
        'path' => $name,
        'linkUrl' => $target,
        'baseUrl' => $baseUrl !== '' ? $baseUrl : $target,
        'visible' => !$pendingApproval,
        'modifiedAt' => $now,
    ];
    if ($categories !== [] || $poffNode !== []) {
        $treeItem['categories'] = $categories;
        $treeItem['work'] = [
            'type' => 'link',
            'categories' => $categories,
        ];
    }
    if ($poffNode !== []) {
        $treeItem['poffNode'] = $poffNode;
    }
    if ($pendingApproval) {
        $treeItem['externalSubmission'] = true;
        $treeItem['approvalStatus'] = 'pending';
        $treeItem['submittedAt'] = $now;
    }
    $tree[] = $treeItem;

    $config['tree'] = $tree;
    $config['treeHash'] = hash('sha256', json_encode($tree));
    $config['updatedAt'] = $now;

    $configPath = PoffConfig::configPath($targetDir);
    $dirPath = dirname($configPath);
    $dirError = cmsEnsureUploadDirectory($dirPath, 'Failed to create config directory.');
    if ($dirError !== null) {
        return $dirError;
    }

    $encoded = json_encode($config, JSON_PRETTY_PRINT | JSON_UNESCAPED_SLASHES);
    if ($encoded === false || file_put_contents($configPath, $encoded) === false) {
        return cmsUploadErrorResult('Failed to write config file.');
    }

    if (!$pendingApproval) {
        $htaccessDir = trim((string) ($options['htaccessDir'] ?? ''));
        cmsEnsureHtaccessFrameAncestorForUrl($htaccessDir !== '' ? $htaccessDir : $targetDir, $target);
    }

    return cmsUploadStoredResult($name, [
        'linkUrl' => $target,
        'baseUrl' => $baseUrl !== '' ? $baseUrl : $target,
        'pendingApproval' => $pendingApproval,
    ]);
}

function cmsNormalizeRemoteBaseUrl(string $url): string
{
    $trimmed = trim($url);
    if ($trimmed === '') {

    }

    $parts = parse_url($trimmed);

        return rtrim($trimmed, '/');
    }

    $normalized = $parts['scheme'] . '://' . $parts['host'];
    if (isset($parts['port'])) {
        $normalized .= ':' . $parts['port'];
    }
    $path = trim((string) ($parts['path'] ?? ''), '/');
    if ($path !== '') {
        $normalized .= '/' . $path;
    }

    return rtrim($normalized, '/');
}

function cmsExternalFrameAncestorOrigin(string $url): string
{
    $trimmed = trim($url);
    if ($trimmed === '') {
        return '';
    }

    $parts = parse_url($trimmed);
    if (!is_array($parts) || empty($parts['scheme']) || empty($parts['host'])) {
        return '';
    }

    $scheme = strtolower((string) $parts['scheme']);
    if (!in_array($scheme, ['http', 'https'], true)) {
        return '';
    }

    $origin = $scheme . '://' . $parts['host'];
    if (isset($parts['port'])) {
        $origin .= ':' . $parts['port'];
    }

    return $origin;
}

function cmsAppendFrameAncestorToPolicy(string $policyLine, string $origin): string
{
    if ($origin === '' || strpos($policyLine, 'frame-ancestors') === false) {
        return $policyLine;
    }
    if (preg_match('/\bframe-ancestors\s+\*/i', $policyLine) === 1) {
        return $policyLine;
    }
    if (strpos($policyLine, $origin) !== false) {
        return $policyLine;
    }

    return preg_replace_callback(
        '/(frame-ancestors\s+)([^"]+)/i',
        static function (array $matches) use ($origin): string {
            $existing = trim((string) ($matches[2] ?? ''));
            $updated = $existing === '' ? $origin : ($existing . ' ' . $origin);
            return (string) ($matches[1] ?? 'frame-ancestors ') . $updated;
        },
        $policyLine,
        1
    ) ?? $policyLine;
}

function cmsEnsureHtaccessFrameAncestorForUrl(string $targetDir, string $url): void
{
    $origin = cmsExternalFrameAncestorOrigin($url);
    if ($origin === '') {
        return;
    }

    $dirError = cmsEnsureUploadDirectory($targetDir);
    if ($dirError !== null) {
        return;
    }

    $htaccessPath = rtrim($targetDir, DIRECTORY_SEPARATOR) . DIRECTORY_SEPARATOR . '.htaccess';
    $contents = is_file($htaccessPath) ? (string) file_get_contents($htaccessPath) : '';
    if (trim($contents) === '') {
        $contents = cmsDefaultHtaccessContents();
    }

    $lines = preg_split("/\r\n|\n|\r/", $contents) ?: [];
    $updated = false;
    foreach ($lines as $index => $line) {
        $trimmed = ltrim($line);
        if ($trimmed === '' || str_starts_with($trimmed, '#')) {
            continue;
        }
        if (stripos($line, 'Header always set Content-Security-Policy') === false || stripos($line, 'frame-ancestors') === false) {
            continue;
        }
        $nextLine = cmsAppendFrameAncestorToPolicy($line, $origin);
        if ($nextLine !== $line) {
            $lines[$index] = $nextLine;
        }
        $updated = true;
        break;
    }

    if (!$updated) {
        $block = [
            '',
            '# Allow embedded preview for linked external client origins',
            '<IfModule mod_headers.c>',
            '    Header always set Content-Security-Policy "frame-ancestors \'self\' ' . $origin . '"',
            '</IfModule>',
        ];
        $contents = rtrim($contents);
        $contents .= ($contents === '' ? '' : PHP_EOL) . implode(PHP_EOL, $block) . PHP_EOL;
    } else {
        $contents = implode(PHP_EOL, $lines);
        if ($contents !== '' && !str_ends_with($contents, PHP_EOL)) {
            $contents .= PHP_EOL;
        }
    }

    @file_put_contents($htaccessPath, $contents);
}

function mcpHideMatchingThumbnailEntries(string $folderDir): array
{
    if (!class_exists('PoffConfig')) {
        return ['count' => 0, 'error' => 'Poff config unavailable.'];
    }

    $config = PoffConfig::ensure($folderDir);
    $tree = is_array($config['tree'] ?? null) ? $config['tree'] : [];
    $mainStems = [];
    foreach ($tree as $item) {
        if (!is_array($item) || (string) ($item['type'] ?? 'file') === 'folder') {
            continue;
        }
        $stem = strtolower(pathinfo((string) ($item['name'] ?? ''), PATHINFO_FILENAME));
        if ($stem !== '' && preg_match('/^thumb(?:[._ -]+)?(.+)$/i', $stem) !== 1) {
            $mainStems[$stem] = true;
        }
    }

    $count = 0;
    foreach ($tree as &$item) {
        if (!is_array($item) || (string) ($item['type'] ?? 'file') === 'folder') {
            continue;
        }
        $stem = strtolower(pathinfo((string) ($item['name'] ?? ''), PATHINFO_FILENAME));
        if ($stem === '' || preg_match('/^thumb(?:[._ -]+)?(.+)$/i', $stem, $matches) !== 1) {
            continue;
        }
        $mainStem = strtolower(trim((string) ($matches[1] ?? ''), "._- "));
        if ($mainStem === '' || !isset($mainStems[$mainStem])) {
            continue;
        }
        $item['visible'] = false;
        $count++;
    }
    unset($item);

    if ($count === 0) {
        return ['count' => 0, 'error' => null];
    }
    $config['tree'] = $tree;
    $config['treeHash'] = hash('sha256', json_encode($tree));
    $config['updatedAt'] = date('c');
    $error = mcpWriteJsonFile(PoffConfig::configPath($folderDir), $config);
    return ['count' => $count, 'error' => $error];

function mcpConverterCatalogRequest(string $url, array $payload): array
{
    $override = $GLOBALS['__poff_converter_catalog_post'] ?? null;
    if (is_callable($override)) {
        $response = $override($url, $payload);
        return is_array($response) ? $response : ['ok' => false, 'status' => 0, 'body' => ''];
    }

    $context = stream_context_create([
        'http' => [
            'method' => 'POST',
            'header' => "Content-Type: application/json\r\nAccept: application/json",
            'content' => json_encode($payload, JSON_UNESCAPED_SLASHES),
            'timeout' => 20,
            'ignore_errors' => true,
            'follow_location' => 0,
            'max_redirects' => 0,
        ],
    ]);
    $body = @file_get_contents($url, false, $context);
    $status = 0;
    foreach (($http_response_header ?? []) as $header) {
        if (preg_match('#^HTTP/\S+\s+(\d{3})#i', (string) $header, $matches)) {
            $status = (int) $matches[1];
            break;
        }
    }
    return [
        'ok' => $body !== false && $status >= 200 && $status < 300,
        'status' => $status,
        'body' => $body !== false ? $body : '',
    ];

function mcpSanitizeRelPath(string $path): string
{
    $parts = preg_split('/[\\/]+/', $path) ?: [];
    $cleanParts = [];

    foreach ($parts as $part) {
        $part = trim($part);
        if ($part === '' || $part === '.' || $part === '..') {
            continue;
        }
        $clean = preg_replace('/[^a-zA-Z0-9._-]+/', '-', $part);
        $clean = trim($clean, '-');
        if ($clean !== '') {
            $cleanParts[] = $clean;
        }
    }

    return $cleanParts === [] ? 'untitled' : implode(DIRECTORY_SEPARATOR, $cleanParts);
}

function mcp_sanitize_relpath(string $path): string
{
    // Internal compatibility wrapper for older MCP helper callers.
    return mcpSanitizeRelPath($path);

function mcpCopyRecursive(string $src, string $dst): void
{
    if (is_dir($src)) {
        if (!is_dir($dst)) {
            mkdir($dst, 0755, true);
        }
        $items = scandir($src);
        if ($items === false) {
            return;
        }
        foreach ($items as $item) {
            if ($item === '.' || $item === '..') {
                continue;
            }
            $from = $src . DIRECTORY_SEPARATOR . $item;
            $to = $dst . DIRECTORY_SEPARATOR . $item;
            mcpCopyRecursive($from, $to);
        }
    } else {
        $dir = dirname($dst);
        if (!is_dir($dir)) {
            mkdir($dir, 0755, true);
        }
        copy($src, $dst);

function mcpUrlHostIsPrivate(string $host): bool
{
    if ($host === '') {
        return true;
    }
    if ($host === 'localhost' || str_ends_with($host, '.localhost')) {
        return true;
    }

    $ips = gethostbynamel($host);
    if (!is_array($ips) || $ips === []) {
        $ips = [$host];
    }

    foreach ($ips as $ip) {
        if (filter_var($ip, FILTER_VALIDATE_IP, FILTER_FLAG_IPV4) !== false) {
            $isPublic = filter_var(
                $ip,
                FILTER_VALIDATE_IP,
                FILTER_FLAG_IPV4 | FILTER_FLAG_NO_PRIV_RANGE | FILTER_FLAG_NO_RES_RANGE
            );
            if ($isPublic === false) {
                return true;
            }
            continue;
        }
        if (filter_var($ip, FILTER_VALIDATE_IP, FILTER_FLAG_IPV6) !== false) {
            if ($ip === '::1' || str_starts_with(strtolower($ip), 'fe80:') || str_starts_with(strtolower($ip), 'fc') || str_starts_with(strtolower($ip), 'fd')) {
                return true;
            }
            $isPublic = filter_var(
                $ip,
                FILTER_VALIDATE_IP,
                FILTER_FLAG_IPV6 | FILTER_FLAG_NO_PRIV_RANGE | FILTER_FLAG_NO_RES_RANGE
            );
            if ($isPublic === false) {
                return true;
            }
        }
    }

    return false;
}

{
    // Internal compatibility wrapper for older MCP helper callers.
    return mcpUrlHostIsPrivate($host);

function mcpPromptResponseCandidates(string $raw): array
{
    $trimmed = trim($raw);
    if ($trimmed === '') {
        return [];
    }

    $candidates = [$trimmed];

    if (preg_match_all('/```(?:[a-z0-9_-]+)?\s*([\s\S]*?)```/i', $trimmed, $matches)) {
        foreach ($matches[1] as $match) {
            $candidate = trim((string) $match);
            if ($candidate !== '') {
                $candidates[] = $candidate;
            }
        }
    }

    $firstBrace = strpos($trimmed, '{');
    $lastBrace = strrpos($trimmed, '}');
    if ($firstBrace !== false && $lastBrace !== false && $lastBrace > $firstBrace) {
        $candidate = trim(substr($trimmed, $firstBrace, $lastBrace - $firstBrace + 1));
        if ($candidate !== '') {
            $candidates[] = $candidate;
        }
    }

    $normalized = [];
    foreach ($candidates as $candidate) {
        if (in_array($candidate, $normalized, true)) {
            continue;
        }
        $normalized[] = $candidate;
    }

    return $normalized;
}

function mcpPromptDecodeLooseString(string $value): string
{
    $trimmed = trim($value);
    if ($trimmed === '') {
        return '';
    }

    $decoded = json_decode($trimmed, true);
    if (is_string($decoded)) {
        return $decoded;
    }

    if ($trimmed[0] === '"') {
        $trimmed = substr($trimmed, 1);
    }
    if ($trimmed !== '' && substr($trimmed, -1) === '"') {
        $trimmed = substr($trimmed, 0, -1);
    }

    return stripcslashes($trimmed);
}

function mcpPromptExtractLooseScalarField(string $payload, string $key): ?string
{
    $knownKeys = [
        'template',
        'css',
        'style',
        'js',
        'script',
        'work',
        'title',
        'description',
        'model',
        'content',
        'response',
    ];
    $otherKeys = array_values(array_filter($knownKeys, static fn (string $candidate): bool => $candidate !== $key));
    $otherKeysPattern = implode('|', array_map(static fn (string $candidate): string => preg_quote($candidate, '/'), $otherKeys));
    $pattern = '/"' . preg_quote($key, '/') . '"\s*:\s*([\s\S]*?)(?=\s*(?:,\s*"(?:' . $otherKeysPattern . ')"\s*:|\}\s*$|$))/i';
    if (preg_match($pattern, $payload, $matches) !== 1) {
        return null;
    }

    return mcpPromptDecodeLooseString((string) $matches[1]);
}

function mcpPromptDecodeLoosePayload(string $raw): ?array
{
    $candidates = mcpPromptResponseCandidates($raw);
    foreach ($candidates as $candidate) {
        $decoded = json_decode($candidate, true);
        if (is_array($decoded)) {
            return $decoded;
        }
    }

    foreach ($candidates as $candidate) {
        if (!preg_match('/"(template|css|style|js|script|title|description|model|content|response)"\s*:/i', $candidate)) {
            continue;
        }

        $result = [];
        foreach (['template', 'css', 'style', 'js', 'script', 'title', 'description', 'model', 'content', 'response'] as $key) {
            $value = mcpPromptExtractLooseScalarField($candidate, $key);
            if ($value !== null) {
                $result[$key] = $value;
            }
        }

        if ($result !== []) {
            return $result;
        }
    }

    return null;
}

            $template = trim(implode("\n", array_filter($parts)));
        }
    } elseif (isset($decoded['choices'][0]['text']) && is_scalar($decoded['choices'][0]['text'])) {
        $extractedFromEnvelope = true;
        $template = trim((string) $decoded['choices'][0]['text']);
    } elseif (isset($decoded['message']['content']) && is_scalar($decoded['message']['content'])) {
        $extractedFromEnvelope = true;
        $template = trim((string) $decoded['message']['content']);
    } elseif (isset($decoded['response']) && is_scalar($decoded['response'])) {
        $extractedFromEnvelope = true;
        $template = trim((string) $decoded['response']);
    } elseif (isset($decoded['template'])) {
        $template = trim((string) $decoded['template']);
    } elseif (isset($decoded['content'])) {
        $template = trim((string) $decoded['content']);
    }

    if ($extractedFromEnvelope && $template !== '' && $template !== $trimmed) {
        return mcpParsePromptModelResult($template);
    }

    if ($extractedFromEnvelope && $template === '') {
        return ['template' => ''];
    }

    if ($template === '') {
        return ['template' => ''];
    }

    $result = ['template' => cmsSanitizePromptTemplateForTarget($template, false)];
    foreach (['title', 'description', 'model'] as $key) {
        if (isset($decoded[$key]) && is_scalar($decoded[$key])) {
            $result[$key] = trim((string) $decoded[$key]);
        }
    }
    if (isset($decoded['work']) && is_array($decoded['work'])) {
        $result['work'] = $decoded['work'];
    }
    if (isset($decoded['treeVisible']) && is_array($decoded['treeVisible'])) {
        $result['treeVisible'] = array_values(array_filter($decoded['treeVisible'], static fn(mixed $value): bool => is_scalar($value)));
    }
    if (array_key_exists('css', $decoded) || array_key_exists('style', $decoded)) {
        $result['css'] = (string) ($decoded['css'] ?? $decoded['style'] ?? '');
    }
    if (array_key_exists('js', $decoded) || array_key_exists('script', $decoded)) {
        $result['js'] = (string) ($decoded['js'] ?? $decoded['script'] ?? '');
    }

    return $result;
}

function mcpPromptValidateScopedCss(string $css): array
{
    $errors = [];
    $trimmed = trim($css);

    if ($trimmed === '') {
        return $errors;
    }

    if (preg_match('/<\s*style\b/i', $trimmed)) {
        $errors[] = 'CSS must not include <style> tags.';
    }

    if (preg_match('/@import\s/i', $trimmed)) {
        $errors[] = 'CSS must not import external stylesheets.';
    }

    if (preg_match('/(^|[{}>])\s*(html|body|:root|\*)\s*(?:[,{]|$)/i', $trimmed)) {
        $errors[] = 'CSS must not include global html/body/:root/universal selectors.';
    }

    if (preg_match('/\b(?:position\s*:\s*fixed|z-index\s*:\s*9999)/i', $trimmed)) {
        $errors[] = 'CSS should not create global overlay behavior.';
    }

    return $errors;
}

function mcpPromptLoadEnv(string $rootDir): array
{
    $envPath = rtrim($rootDir, DIRECTORY_SEPARATOR) . DIRECTORY_SEPARATOR . '.env';
    if (!is_file($envPath)) {
        return [];
    }
    $lines = file($envPath, FILE_IGNORE_NEW_LINES | FILE_SKIP_EMPTY_LINES) ?: [];
    $env = [];
    foreach ($lines as $line) {
        $line = trim($line);
        if ($line === '' || str_starts_with($line, '#')) {
            continue;
        }
        $parts = explode('=', $line, 2);
        if (count($parts) !== 2) {
            continue;
        }
        $key = trim($parts[0]);
        $value = trim($parts[1]);
        $value = trim($value, " \t\n\r\0\x0B\"'");
        if ($key !== '') {
            $env[$key] = $value;
        }
    }
    return $env;
}

function mcpPromptEnvValue(array $env, string $key): ?string
{
    $value = getenv($key);
    if (is_string($value) && $value !== '') {
        return $value;
    }
    return $env[$key] ?? null;
}

function mcpPromptHttpPost(string $url, array $headers, array $payload): array
{
    $override = $GLOBALS['__poff_mcp_prompt_http_post'] ?? null;
    if (is_callable($override)) {
        $response = $override($url, $headers, $payload);
        if (is_array($response)) {
            return $response;
        }
    }

    if (function_exists('set_time_limit')) {
        @set_time_limit(MCP_PROMPT_HTTP_TIMEOUT_SECONDS + 30);
    }

    $previousSocketTimeout = ini_get('default_socket_timeout');
    if (function_exists('ini_set')) {
        @ini_set('default_socket_timeout', (string) MCP_PROMPT_HTTP_TIMEOUT_SECONDS);
    }

    $headerLines = array_merge(['Content-Type: application/json'], $headers);
    try {
        $context = stream_context_create([
            'http' => [
                'method' => 'POST',
                'header' => implode("\r\n", $headerLines),
                'content' => json_encode($payload),
                'timeout' => MCP_PROMPT_HTTP_TIMEOUT_SECONDS,
                'ignore_errors' => true,
            ],
        ]);
        $response = @file_get_contents($url, false, $context);
    } finally {
        if ($previousSocketTimeout !== false && function_exists('ini_set')) {
            @ini_set('default_socket_timeout', (string) $previousSocketTimeout);
        }
    }
    $status = 0;
    $statusLine = '';
    if (isset($http_response_header[0]) && preg_match('/\s(\d{3})\s/', $http_response_header[0], $matches)) {
        $status = (int) $matches[1];
        $statusLine = (string) $http_response_header[0];
    }
    return [
        'ok' => $response !== false && $status >= 200 && $status < 400,
        'status' => $status,
        'statusLine' => $statusLine,
        'body' => $response !== false ? $response : '',
    ];
}

function mcpPromptNormalizeErrorText(string $text): string
{
    $normalized = html_entity_decode(strip_tags($text), ENT_QUOTES | ENT_HTML5, 'UTF-8');
    $normalized = preg_replace('/\s+/', ' ', $normalized) ?? $normalized;
    $normalized = preg_replace('/sk-[A-Za-z0-9_-]{12,}/', 'sk-***', $normalized) ?? $normalized;
    $normalized = preg_replace('/AIza[0-9A-Za-z_-]{12,}/', 'AIza***', $normalized) ?? $normalized;
    $normalized = trim($normalized, " \t\n\r\0\x0B.:");
    if ($normalized === '') {
        return '';
    }
    if (strlen($normalized) > 220) {
        $normalized = substr($normalized, 0, 217) . '...';
    }

    return $normalized;
}

function mcpPromptExtractErrorDetail(mixed $value): string
{
    if (is_string($value)) {
        $trimmed = trim($value);
        if ($trimmed === '') {
            return '';
        }
        $decoded = json_decode($trimmed, true);
        if (is_array($decoded)) {
            $detail = mcpPromptExtractErrorDetail($decoded);
            if ($detail !== '') {
                return $detail;
            }
        }
        if (preg_match('/<title[^>]*>(.*?)<\/title>/is', $trimmed, $matches)) {
            return mcpPromptNormalizeErrorText((string) $matches[1]);
        }

        return mcpPromptNormalizeErrorText($trimmed);
    }

    if (!is_array($value)) {
        return '';
    }

    foreach (['message', 'detail'] as $key) {
        if (array_key_exists($key, $value)) {
            $detail = mcpPromptExtractErrorDetail($value[$key]);
            if ($detail !== '') {
                return $detail;
            }
        }
    }

    if (array_key_exists('error', $value)) {
        $detail = mcpPromptExtractErrorDetail($value['error']);
        if ($detail !== '') {
            return $detail;
        }
    }

    if (array_key_exists('details', $value)) {
        $detail = mcpPromptExtractErrorDetail($value['details']);
        if ($detail !== '') {
            return $detail;
        }
    }

    foreach ($value as $item) {
        $detail = mcpPromptExtractErrorDetail($item);
        if ($detail !== '') {
            return $detail;
        }
    }

    return '';
}

function mcpPromptFormatHttpError(string $label, array $response): string
{
    $status = (int) ($response['status'] ?? 0);
    $detail = mcpPromptExtractErrorDetail($response['body'] ?? '');
    $message = $label . ' request failed';
    if ($status > 0) {
        $message .= ' (HTTP ' . $status . ')';
    }
    if ($detail !== '') {
        $message .= ': ' . $detail;
    }

    return $message . '.';
}

function mcpPromptOuterWrapperReference(array $layoutValue): array
{
    $layoutName = trim((string) ($layoutValue['name'] ?? Worktype::defaultLayoutName()));
    if ($layoutName === '') {
        $layoutName = Worktype::defaultLayoutName();
    }

    $storage = trim((string) ($layoutValue['storage'] ?? ''));
    if ($storage === '') {
        $storage = 'default';
    }

    $templateName = $layoutName;
    $templateCandidate = Worktype::template($templateName);
    if (!is_string($templateCandidate) || $templateCandidate === '') {
        $templateName = Worktype::defaultLayoutName();
        $templateCandidate = Worktype::template($templateName);
    }

    $template = '';
    if (isset($layoutValue['template']) && is_string($layoutValue['template']) && trim($layoutValue['template']) !== '') {
        $template = $layoutValue['template'];
    } else {
        $template = (string) ($templateCandidate ?? '');
    }

    $css = '';
    if (isset($layoutValue['css']) && is_string($layoutValue['css']) && trim($layoutValue['css']) !== '') {
        $css = $layoutValue['css'];
    } else {
        $css = (string) (Worktype::layoutBundleAsset($templateName, 'style.css') ?? '');
    }

    $js = '';
    if (isset($layoutValue['js']) && is_string($layoutValue['js']) && trim($layoutValue['js']) !== '') {
        $js = $layoutValue['js'];
    } else {
        $js = (string) (Worktype::layoutBundleAsset($templateName, 'script.js') ?? '');
    }

    return [
        'name' => $layoutName,
        'storage' => $storage,
        'sectionPartial' => 'works',
        'source' => $storage === 'filesystem'
            ? 'resolved active wrapper'
            : ($storage === 'inline' ? 'inline wrapper config' : 'bundled default wrapper reference'),
        'template' => $template,
        'css' => $css,
        'js' => $js,
    ];
}

function mcpBuildPromptRef(string $basePath, array $item): ?array
{
    $name = trim((string) ($item['name'] ?? $item['path'] ?? ''));
    if ($name === '') {
        return null;
    }

    $configuredType = strtolower(trim((string) ($item['type'] ?? 'file')));
    $explicitLinkTarget = cmsConfiguredTreeLinkTarget($item);
    $relativePath = cmsConfiguredTreeDisplayPath($basePath, $item, $name);
    if ($relativePath === '') {
        $relativePath = cmsConfiguredTreeFilesystemRelativePath($basePath, $item, $name);
    }

    $isFolder = $configuredType === 'folder';
    $kind = $isFolder
        ? 'folder'
        : (($configuredType === 'link' || $explicitLinkTarget !== '') ? 'link' : mcpPromptRefKind($name, $configuredType));
    $pageLink = $explicitLinkTarget !== ''
        ? $explicitLinkTarget
        : mcpPromptViewerUrl($relativePath, !$isFolder);
    $assetUrl = $explicitLinkTarget !== ''
        ? $explicitLinkTarget
        : mcpPromptAssetUrl($relativePath, !$isFolder);
    $linkUrl = cmsConfiguredTreeExternalLinkUrl($item);

    $result = array_merge([
        'name' => $name,
        'title' => (string) ($item['title'] ?? $name),
        'slug' => (string) ($item['slug'] ?? PoffConfig::slugify($name)),
        'type' => $isFolder ? 'folder' : 'file',
        'kind' => $kind,
        'path' => $relativePath,
        'isFolder' => $isFolder,
        'isFile' => !$isFolder,
        'visible' => array_key_exists('visible', $item) ? (bool) $item['visible'] : true,
    ], mcpPromptUrlAliases($pageLink, $assetUrl));

    if ($linkUrl !== '') {
        $result['linkUrl'] = $linkUrl;
    }

    return $result;
}

function mcpBuildPromptContext(string $relativePath, array $config, array $folderViewData = []): array
{
    $normalizedPath = trim($relativePath, "/\\");
    $currentName = (string) ($config['folderName'] ?? basename($normalizedPath));
    $currentPageLink = mcpPromptViewerUrl($normalizedPath, false);
    $currentAssetUrl = mcpPromptAssetUrl($normalizedPath, false);
    $layoutValue = is_array($config['work'] ?? null) && is_array($config['work']['layout'] ?? null)
        ? $config['work']['layout']
        : [];
    $rootTitle = trim((string) ($config['title'] ?? $currentName));
    if ($rootTitle === '') {
        $rootTitle = $currentName;
    }
    $rootFolderName = trim((string) ($config['folderName'] ?? $currentName));
    if ($rootFolderName === '') {
        $rootFolderName = $currentName;
    }
    $rootSlug = trim((string) ($config['slug'] ?? ''));
    if ($rootSlug === '') {
        $rootSlug = PoffConfig::slugify($rootFolderName);
    }
    $rootDescription = trim((string) ($config['description'] ?? ''));
    $workSource = is_array($config['work'] ?? null) ? $config['work'] : [];
    $workTitle = trim((string) ($workSource['title'] ?? $currentName));
    if ($workTitle === '') {
        $workTitle = $currentName;
    }
    $workName = trim((string) ($workSource['name'] ?? $currentName));
    if ($workName === '') {
        $workName = $currentName;
    }
    $workSlug = trim((string) ($workSource['slug'] ?? ''));
    if ($workSlug === '') {
        $workSlug = $rootSlug;
    }
    $workDescription = trim((string) ($workSource['description'] ?? $rootDescription));
    $workType = trim((string) ($workSource['type'] ?? 'folder'));
    if ($workType === '') {
        $workType = 'folder';
    }

    $context = [
        'current' => array_merge([
            'targetType' => 'folder',
            'sectionPartial' => 'works',
            'title' => $rootTitle,
            'name' => $currentName,
            'path' => $normalizedPath,
            'templateTarget' => mcpPromptTemplateTarget($normalizedPath),
            'layoutTemplateTarget' => mcpPromptLayoutTemplateTarget($normalizedPath),
            'outerWrapper' => mcpPromptOuterWrapperReference($layoutValue),
            'root' => [
                'title' => $rootTitle,
                'name' => $rootFolderName,
                'folderName' => $rootFolderName,
                'path' => $normalizedPath,
                'slug' => $rootSlug,
                'description' => $rootDescription,
                'type' => 'folder',
            ],
            'work' => [
                'title' => $workTitle,
                'name' => $workName,
                'path' => $normalizedPath,
                'slug' => $workSlug,
                'description' => $workDescription,
                'type' => $workType,
                'kind' => $workType,
            ],
        ], mcpPromptUrlAliases($currentPageLink, $currentAssetUrl)),
        'items' => [],
        'allItems' => [],
        'allFiles' => [],
        'allFolders' => [],
        'allImages' => [],
        'allVideos' => [],
        'allAudio' => [],
        'allPdfs' => [],
        'allTexts' => [],
        'allLinks' => [],
        'allOther' => [],
    ];
    if (is_array($folderViewData['tree'] ?? null)) {
        $context['current']['tree'] = $folderViewData['tree'];
        $context['current']['workTree'] = $folderViewData['workTree'] ?? null;
        foreach (['allItems', 'allFiles', 'allFolders', 'allImages', 'allVideos', 'allAudio', 'allPdfs', 'allTexts', 'allLinks', 'allOther'] as $key) {
            if (array_key_exists($key, $folderViewData) && is_array($folderViewData[$key])) {
                $context['current'][$key] = $folderViewData[$key];
                $context[$key] = $folderViewData[$key];
            }
        }
        $context['items'] = $folderViewData['tree'];
        $context['allItems'] = $folderViewData['allItems'] ?? [];
        $context['allFiles'] = $folderViewData['allFiles'] ?? [];
        $context['allFolders'] = $folderViewData['allFolders'] ?? [];
        $context['allImages'] = $folderViewData['allImages'] ?? [];
        $context['allVideos'] = $folderViewData['allVideos'] ?? [];
        $context['allAudio'] = $folderViewData['allAudio'] ?? [];
        $context['allPdfs'] = $folderViewData['allPdfs'] ?? [];
        $context['allTexts'] = $folderViewData['allTexts'] ?? [];
        $context['allLinks'] = $folderViewData['allLinks'] ?? [];
        $context['allOther'] = $folderViewData['allOther'] ?? [];
    }

    $tree = is_array($config['tree'] ?? null) ? $config['tree'] : [];
    foreach ($tree as $item) {
        if (!is_array($item)) {
            continue;
        }
        $ref = mcpBuildPromptRef($normalizedPath, $item);
        if ($ref === null) {
            continue;
        }
        $context['items'][] = $ref;
        $context['allItems'][] = $ref;
        if ($ref['isFolder']) {
            $context['allFolders'][] = $ref;
            continue;
        }

        $context['allFiles'][] = $ref;
        switch ($ref['kind']) {
            case 'image':
                $context['allImages'][] = $ref;
                break;
            case 'video':
                $context['allVideos'][] = $ref;
                break;
            case 'audio':
                $context['allAudio'][] = $ref;
                break;
            case 'pdf':
                $context['allPdfs'][] = $ref;
                break;
            case 'text':
                $context['allTexts'][] = $ref;
                break;
            case 'link':
                $context['allLinks'][] = $ref;
                break;
            default:
                $context['allOther'][] = $ref;
                break;
        }
    }

    return $context;
}

function mcpPromptTrimText(string $text, int $maxLength = 240): string
{
    $normalized = preg_replace('/\s+/', ' ', trim($text)) ?? trim($text);
    if (strlen($normalized) <= $maxLength) {
        return $normalized;
    }

    return substr($normalized, 0, max(0, $maxLength - 3)) . '...';
}

function mcpPromptCompactRef(array $ref): array
{
    $compact = [];
    foreach (['name', 'title', 'type', 'kind', 'path', 'pageLink', 'linkUrl', 'srcUrl', 'isFolder', 'isFile', 'visible'] as $key) {
        if (!array_key_exists($key, $ref)) {
            continue;
        }
        $value = $ref[$key];
        $compact[$key] = is_string($value) ? mcpPromptTrimText($value, 160) : $value;
    }

    return $compact;
}

function mcpPromptCompactTreeItems(array $items, int $maxDepth = 3, int $maxChildren = 12): array
{
    $compactItems = [];
    foreach (array_slice($items, 0, $maxChildren) as $item) {
        if (!is_array($item)) {
            continue;
        }

        $compact = mcpPromptCompactRef($item);
        if (array_key_exists('childCount', $item) && is_scalar($item['childCount'])) {
            $compact['childCount'] = (int) $item['childCount'];
        }

        if ($maxDepth > 0 && is_array($item['children'] ?? null) && $item['children'] !== []) {
            $compact['children'] = mcpPromptCompactTreeItems($item['children'], $maxDepth - 1, $maxChildren);
        }

        $compactItems[] = $compact;
    }

    return $compactItems;
}

function mcpPromptCompactContext(array $context): array
{
    $current = is_array($context['current'] ?? null) ? $context['current'] : [];
    if (is_array($current['outerWrapper'] ?? null)) {
        $outerWrapper = [];
        foreach (['name', 'storage', 'sectionPartial', 'source'] as $key) {
            if (array_key_exists($key, $current['outerWrapper'])) {
                $outerWrapper[$key] = $current['outerWrapper'][$key];
            }
        }
        foreach (['template', 'css', 'js'] as $key) {
            if (isset($current['outerWrapper'][$key]) && is_string($current['outerWrapper'][$key]) && $current['outerWrapper'][$key] !== '') {
                $outerWrapper[$key] = mcpPromptTrimText($current['outerWrapper'][$key], 2200);
                $outerWrapper[$key . 'Length'] = strlen($current['outerWrapper'][$key]);
            }
        }
        $current['outerWrapper'] = $outerWrapper;
    }
    if (is_array($current['root'] ?? null)) {
        $root = [];
        foreach (['title', 'name', 'folderName', 'path', 'slug', 'description', 'type'] as $key) {
            if (!array_key_exists($key, $current['root'])) {
                continue;
            }
            $value = $current['root'][$key];
            $root[$key] = is_string($value)
                ? mcpPromptTrimText($value, 220)
                : $value;
        }
        $current['root'] = $root;
    }
    if (is_array($current['work'] ?? null)) {
        $work = [];
        foreach (['title', 'name', 'path', 'slug', 'description', 'type', 'kind'] as $key) {
            if (!array_key_exists($key, $current['work'])) {
                continue;
            }
            $value = $current['work'][$key];
            $work[$key] = is_string($value)
                ? mcpPromptTrimText($value, 220)
                : $value;
        }
        $current['work'] = $work;
    }
    if (is_array($current['tree'] ?? null)) {
        $current['tree'] = mcpPromptCompactTreeItems($current['tree']);
    }
    if (is_array($current['workTree'] ?? null)) {
        $current['workTree']['children'] = mcpPromptCompactTreeItems(
            is_array($current['workTree']['children'] ?? null) ? $current['workTree']['children'] : [],
            3,
            12
        );
    }

    $items = is_array($context['items'] ?? null)
        ? mcpPromptCompactTreeItems($context['items'])
        : [];

    $counts = [
        'items' => count(is_array($context['items'] ?? null) ? $context['items'] : []),

{

        return true;
    }

    }

function mcpRemoteAbsoluteUrl(string $baseUrl, string $value): string
{
    $trimmed = trim($value);
    if ($trimmed === '') {
        return '';
    }
    if (cmsIsExternalLinkTarget($trimmed) || cmsIsHashLinkTarget($trimmed)) {
        return $trimmed;
    }

    $parts = parse_url($baseUrl);
    $scheme = (string) ($parts['scheme'] ?? 'https');
    $host = (string) ($parts['host'] ?? '');
    $port = isset($parts['port']) ? ':' . (string) $parts['port'] : '';
    $basePath = (string) ($parts['path'] ?? '/');
    $baseDir = preg_replace('~/[^/]*$~', '/', $basePath);
    if (!is_string($baseDir) || $baseDir === '') {
        $baseDir = '/';
    }

    if (str_starts_with($trimmed, '?')) {
        return $scheme . '://' . $host . $port . $basePath . $trimmed;
    }
    if (str_starts_with($trimmed, '/')) {

function mcpRemoteHttpGet(string $url, array $headers = []): array
{

    if (is_callable($override)) {
        return $override($url, $headers);
    }

    $context = stream_context_create([
        'http' => [
            'method' => 'GET',
            'header' => implode("\r\n", $headers),
            'ignore_errors' => true,
            'timeout' => MCP_REMOTE_HTTP_TIMEOUT_SECONDS,
            'follow_location' => 0,
            'max_redirects' => 0,
        ],

        ],
    ]);

    @ini_set('default_socket_timeout', (string) MCP_REMOTE_HTTP_TIMEOUT_SECONDS);

    $body = @file_get_contents($url, false, $context);
    $responseHeaders = isset($http_response_header) && is_array($http_response_header)
        ? $http_response_header
        : [];

    $status = 0;
    foreach ($responseHeaders as $line) {
        if (preg_match('#^HTTP/\S+\s+(\d{3})#i', $line, $matches)) {
            $status = (int) $matches[1];
            break;
        }
    }

    if ($body === false) {
        return [

        'headers' => $responseHeaders,
        'body' => $body,

    $rawItems = $payload['items'] ?? $payload['tree'] ?? [];
    if (!is_array($rawItems)) {
        return [];
    }

    $usedNames = [];
    foreach ($existingTree as $item) {
        if (!is_array($item)) {
            continue;
        }
        $name = trim((string) ($item['name'] ?? ''));
        if ($name !== '') {
            $usedNames[$name] = true;
        }
    }

    $entries = [];
    foreach ($rawItems as $item) {
        if (!is_array($item)) {
            continue;
        }

        $pageLink = trim((string) ($item['pageLink'] ?? ''));
        if ($pageLink === '') {
            continue;
        }

        $preferredName = trim((string) ($item['title'] ?? $item['name'] ?? ''));
        $uniqueName = mcpRemoteUniqueImportedName($preferredName, $sourceId, $usedNames);
        $type = trim((string) ($item['type'] ?? 'file'));
        $isFolder = ($item['isFolder'] ?? false) === true || $type === 'folder';
        $routePath = trim((string) ($item['routePath'] ?? ($item['relativePath'] ?? ($item['path'] ?? ''))));
        $routeSlug = trim((string) ($item['routeSlug'] ?? ''));
        if ($routeSlug === '') {
            $routeBase = $routePath !== '' ? basename(str_replace('\\', '/', $routePath)) : $uniqueName;
            $routeSlug = class_exists('PoffConfig') ? PoffConfig::slugify($routeBase) : (preg_replace('/[^a-z0-9]+/i', '-', strtolower($routeBase)) ?: '');
            $routeSlug = trim($routeSlug, '-');
        }
        $entry = [
            'name' => $uniqueName,
            'title' => trim((string) ($item['title'] ?? $item['name'] ?? $uniqueName)),
            'slug' => $routeSlug !== '' ? $routeSlug : trim((string) ($item['slug'] ?? (class_exists('PoffConfig') ? PoffConfig::slugify($uniqueName) : ''))),
            'routeSlug' => $routeSlug,
            'routePath' => $routePath,
            'type' => $isFolder
                ? 'folder'
                : (trim((string) ($item['kind'] ?? $type)) === 'link' ? 'link' : 'file'),
            'path' => trim((string) ($item['relativePath'] ?? $item['path'] ?? $uniqueName)),
            'pageLink' => $pageLink,
            'linkUrl' => trim((string) ($item['linkUrl'] ?? '')),
            'srcUrl' => trim((string) ($item['srcUrl'] ?? '')),
            'visible' => array_key_exists('visible', $item) ? (bool) $item['visible'] : true,
            'remoteSource' => $sourceId,
            'remoteFeedUrl' => $sourceUrl,
            'remotePath' => trim((string) ($item['path'] ?? '')),
            'remoteKind' => trim((string) ($item['kind'] ?? $type)),
            'externalWork' => true,
            'importedAt' => date('c'),
        ];
        $entries[] = $entry;
    }

    return $entries;
}

function mcpRemotePublicHttpUrl(string $url, ?string $requiredHost = null): ?array
{
    $scheme = strtolower((string) (parse_url($url, PHP_URL_SCHEME) ?? ''));
    $host = strtolower((string) (parse_url($url, PHP_URL_HOST) ?? ''));
    if (!in_array($scheme, ['http', 'https'], true) || $host === '' || mcpRemoteUrlHostIsPrivate($host)) {
        return null;
    }
    if ($requiredHost !== null && strtolower($requiredHost) !== $host) {
        return null;
    }

    return [
        'scheme' => $scheme,
        'host' => $host,
    ];
}

function mcpRemoteFlattenCopyItems(array $items): array
{
    $result = [];
    foreach ($items as $item) {
        if (!is_array($item)) {
            continue;
        }
        $isFolder = ($item['isFolder'] ?? false) === true || (string) ($item['type'] ?? '') === 'folder';
        $srcUrl = trim((string) ($item['srcUrl'] ?? ''));
        if (!$isFolder && $srcUrl !== '') {
            $result[] = $item;
        }
        if (isset($item['children']) && is_array($item['children'])) {
            foreach (mcpRemoteFlattenCopyItems($item['children']) as $child) {
                $result[] = $child;
            }
        }
    }

    return $result;
}

function mcpRemoteSafeCopyName(array $item, int $index): string
{
    $preferred = trim((string) ($item['basename'] ?? $item['name'] ?? ''));
    if ($preferred === '') {
        $path = (string) (parse_url((string) ($item['srcUrl'] ?? ''), PHP_URL_PATH) ?? '');
        $preferred = basename($path);
    }
    $preferred = basename(str_replace('\\', '/', $preferred));
    $preferred = preg_replace('/[^a-z0-9._ -]+/i', '-', $preferred) ?: '';
    $preferred = trim($preferred, ". \t\n\r\0\x0B-");
    if ($preferred === '') {
        $extension = trim((string) ($item['extension'] ?? ''), ". \t\n\r\0\x0B");
        $preferred = 'remote-file-' . ($index + 1) . ($extension !== '' ? '.' . $extension : '');
    }

    return substr($preferred, 0, 180);
}

function mcpRemoteUniqueCopyName(string $name, array &$usedNames): string
{
    $key = strtolower($name);
    if (!isset($usedNames[$key])) {
        $usedNames[$key] = true;
        return $name;
    }

    $extension = pathinfo($name, PATHINFO_EXTENSION);
    $stem = $extension !== '' ? substr($name, 0, -(strlen($extension) + 1)) : $name;
    $suffix = 2;
    do {
        $candidate = $stem . '-' . $suffix . ($extension !== '' ? '.' . $extension : '');
        $suffix++;
    } while (isset($usedNames[strtolower($candidate)]));
    $usedNames[strtolower($candidate)] = true;

    return $candidate;
}

function mcpRemoteRemoveTemporaryDirectory(string $directory): void
{
    if (!is_dir($directory) || !str_starts_with(basename($directory), '.poff-import-')) {
        return;
    }
    $iterator = new RecursiveIteratorIterator(
        new RecursiveDirectoryIterator($directory, FilesystemIterator::SKIP_DOTS),
        RecursiveIteratorIterator::CHILD_FIRST
    );
    foreach ($iterator as $entry) {
        if ($entry->isDir()) {
            @rmdir($entry->getPathname());
        } else {
            @unlink($entry->getPathname());
        }
    }
    @rmdir($directory);
}

function mcpRemoteCopyExport(
    string $rootDir,
    string $targetDir,
    array $payload,
    string $sourceUrl,
    string $destinationName,
    bool $createPlayer
): array {
    $sourceHost = strtolower((string) (parse_url($sourceUrl, PHP_URL_HOST) ?? ''));
    $rawItems = isset($payload['items']) && is_array($payload['items']) ? $payload['items'] : [];
    $items = mcpRemoteFlattenCopyItems($rawItems);
    if ($items === []) {
        return mcpRemoteContentError('The remote work has no downloadable files.');
    }
    if (count($items) > MCP_REMOTE_COPY_MAX_FILES) {
        return mcpRemoteContentError('The remote work contains too many files to copy at once.');
    }

    $fallbackTitle = trim((string) ($payload['root']['title'] ?? $payload['root']['name'] ?? 'remote-work'));
    $folderBase = trim($destinationName) !== '' ? trim($destinationName) : $fallbackTitle;
    $folderBase = preg_replace('/[^a-z0-9._ -]+/i', '-', $folderBase) ?: 'remote-work';
    $folderBase = trim($folderBase, ". \t\n\r\0\x0B-");
    if ($folderBase === '') {
        $folderBase = 'remote-work';
    }
    $folderName = $folderBase;
    $suffix = 2;
    while (file_exists($targetDir . DIRECTORY_SEPARATOR . $folderName)) {
        $folderName = $folderBase . '-' . $suffix;
        $suffix++;
    }

    $temporaryDir = $targetDir . DIRECTORY_SEPARATOR . '.poff-import-' . bin2hex(random_bytes(6));
    if (!mkdir($temporaryDir, 0755, true)) {
        return mcpRemoteContentError('Failed to create a temporary import folder.');
    }

    $tree = [];
    $usedNames = [];
    $totalBytes = 0;
    try {
        foreach ($items as $index => $item) {
            $srcUrl = trim((string) ($item['srcUrl'] ?? ''));
            if (mcpRemotePublicHttpUrl($srcUrl, $sourceHost) === null) {
                throw new RuntimeException('A remote asset URL is not allowed.');
            }
            $response = mcpRemoteHttpGet($srcUrl, ['Accept: application/octet-stream,*/*;q=0.8']);
            $status = (int) ($response['status'] ?? 0);
            if ($status < 200 || $status >= 300) {
                throw new RuntimeException('A remote asset request failed.');
            }
            $body = (string) ($response['body'] ?? '');
            $size = strlen($body);
            if ($size <= 0 || $size > MCP_REMOTE_COPY_MAX_FILE_BYTES) {
                throw new RuntimeException('A remote asset is empty or exceeds the per-file limit.');
            }
            $totalBytes += $size;
            if ($totalBytes > MCP_REMOTE_COPY_MAX_TOTAL_BYTES) {
                throw new RuntimeException('The remote work exceeds the total copy limit.');
            }

            $name = mcpRemoteUniqueCopyName(mcpRemoteSafeCopyName($item, $index), $usedNames);
            if (file_put_contents($temporaryDir . DIRECTORY_SEPARATOR . $name, $body) === false) {
                throw new RuntimeException('Failed to store a copied remote asset.');
            }
            $tree[] = [
                'name' => $name,
                'slug' => PoffConfig::slugify($name),
                'type' => 'file',
                'path' => $name,
                'modifiedAt' => date('c'),
                'visible' => true,
            ];
        }

        $hasVideos = count(array_filter($tree, static fn(array $item): bool => preg_match('/\.(?:mp4|webm|mov|m4v)$/i', (string) $item['name']) === 1)) > 0;
        $workLayout = [
            'mode' => 'poff-layout',
            'name' => 'poff-layout',
            'engine' => 'lightncandy',
            'section' => 'works',
        ];
        if ($createPlayer && $hasVideos) {
            $layoutDir = $temporaryDir . DIRECTORY_SEPARATOR . '.layout';
            if (!mkdir($layoutDir, 0755, true)) {
                throw new RuntimeException('Failed to create the player layout.');
            }
            foreach (mcpRemotePlayerLayoutFiles() as $name => $contents) {
                if (file_put_contents($layoutDir . DIRECTORY_SEPARATOR . $name, $contents) === false) {
                    throw new RuntimeException('Failed to write the player layout.');
                }
            }
            $workLayout = [
                'mode' => 'custom-layout',
                'name' => 'custom-layout',
                'engine' => 'lightncandy',
                'section' => 'works',
                'preset' => 'custom',
            ];
        }

        $config = [
            '$schema' => 'https://dominikeggermann.com/poff-config.schema.json',
            'folderName' => $folderName,
            'slug' => PoffConfig::slugify($folderName),
            'title' => $fallbackTitle !== '' ? $fallbackTitle : $folderName,
            'description' => 'Local copy from ' . $sourceHost,
            'type' => 'folder',
            'id' => 'poff_' . bin2hex(random_bytes(8)),
            'tree' => $tree,
            'treeHash' => hash('sha256', json_encode($tree)),
            'updatedAt' => date('c'),
            'work' => [
                'type' => 'folder',
                'layout' => $workLayout,
                'categories' => $createPlayer && $hasVideos
                    ? ['folder', 'collection', 'video', 'playlist']
                    : ['folder', 'collection'],
                'template' => 'folder',
            ],
            'copiedFrom' => [
                'url' => $sourceUrl,
                'host' => $sourceHost,
                'copiedAt' => date('c'),
            ],
        ];
        $writeError = mcpWriteJsonFile($temporaryDir . DIRECTORY_SEPARATOR . 'poff.config.json', $config);
        if ($writeError !== null) {
            throw new RuntimeException($writeError);
        }

        $finalDir = $targetDir . DIRECTORY_SEPARATOR . $folderName;
        if (!rename($temporaryDir, $finalDir)) {
            throw new RuntimeException('Failed to finish the local copy.');
        }
        $resolvedRootDir = realpath($rootDir) ?: $rootDir;
        $resolvedFinalDir = realpath($finalDir) ?: $finalDir;
        $relativePath = PoffConfig::relativePathFromBase($resolvedFinalDir, $resolvedRootDir);
        $playerCreated = $createPlayer && $hasVideos;
        $firstFileName = trim((string) ($tree[0]['name'] ?? ''));
        $openPath = $playerCreated || $firstFileName === ''
            ? $relativePath
            : trim($relativePath . '/' . $firstFileName, '/');

        return [
            'allowed' => true,
            'saved' => true,
            'mode' => 'copy',
            'copiedCount' => count($tree),
            'copiedBytes' => $totalBytes,
            'destinationName' => $folderName,
            'destinationPath' => $relativePath,
            'openPath' => $openPath,
            'playerCreated' => $playerCreated,
        ];
    } catch (Throwable $error) {
        mcpRemoteRemoveTemporaryDirectory($temporaryDir);
        return mcpRemoteContentError($error->getMessage());
    }
}

function handleImportRemote(array $opts): array
{
    $rootDir = $opts['rootDir'];
    $path = trim((string) ($opts['path'] ?? ''), "/\\");
    $access = mcpEditorAccessState($rootDir, $path);
    if (!$access['allowed']) {
        return array_merge(['route' => 'import-remote'], $access);
    }

    $url = trim((string) ($opts['url'] ?? ''));
    $sourceId = trim((string) ($opts['sourceId'] ?? ''));
    $replace = (bool) ($opts['replace'] ?? false);
    $mode = strtolower(trim((string) ($opts['mode'] ?? 'follow')));
    $destinationName = trim((string) ($opts['destinationName'] ?? ''));
    $createPlayer = (bool) ($opts['createPlayer'] ?? false);

    if (!class_exists('PoffConfig')) {
        return array_merge([
            'route' => 'import-remote',
        ], mcpRemoteContentError('PoffConfig unavailable.'));
    }
    if ($url === '') {
        return array_merge([
            'route' => 'import-remote',
        ], mcpRemoteContentError('Missing remote export URL.'));
    }

    $targetDir = mcpResolveDirectoryInsideRoot($rootDir, $path);
    if ($targetDir === null) {
        return array_merge([
            'route' => 'import-remote',
        ], mcpRemoteContentError('Invalid folder path.'));
    }

    $scheme = strtolower((string) (parse_url($url, PHP_URL_SCHEME) ?? ''));
    $host = strtolower((string) (parse_url($url, PHP_URL_HOST) ?? ''));
    if (!in_array($scheme, ['http', 'https'], true)) {
        return array_merge([
            'route' => 'import-remote',
        ], mcpRemoteContentError('Only http and https remote exports are allowed.'));
    }
    if ($host === '' || mcpRemoteUrlHostIsPrivate($host)) {
        return array_merge([
            'route' => 'import-remote',
        ], mcpRemoteContentError('Remote export host is not allowed.'));
    }

    $response = mcpRemoteHttpGet($url, ['Accept: application/json']);
    if (($response['status'] ?? 0) < 200 || ($response['status'] ?? 0) >= 300) {
        return array_merge([
            'route' => 'import-remote',
            'status' => $response['status'] ?? 0,
        ], mcpRemoteContentError('Remote export request failed.'));
    }

    $payload = json_decode((string) ($response['body'] ?? ''), true);
    if (!is_array($payload)) {
        return array_merge([
            'route' => 'import-remote',
        ], mcpRemoteContentError('Remote export returned invalid JSON.'));
    }

    if ($mode === 'copy') {
        $copyResult = mcpRemoteCopyExport(
            $rootDir,
            $targetDir,
            $payload,
            $url,
            $destinationName,
            $createPlayer
        );
        return array_merge([
            'route' => 'import-remote',
        ], $copyResult);
    }

    $config = PoffConfig::ensure($targetDir);
    $existingTree = isset($config['tree']) && is_array($config['tree']) ? $config['tree'] : [];
    $resolvedSourceId = $sourceId !== '' ? $sourceId : mcpRemoteExportSourceId($url, $payload);
    $importedEntries = mcpRemoteImportTreeEntries($payload, $url, $resolvedSourceId, $existingTree);

    if ($replace) {
        $existingTree = array_values(array_filter($existingTree, static function ($item) use ($resolvedSourceId): bool {
            return !is_array($item) || (string) ($item['remoteSource'] ?? '') !== $resolvedSourceId;
        }));
    }

    $config['tree'] = array_merge($existingTree, $importedEntries);
    $config['treeHash'] = hash('sha256', json_encode($config['tree']));
    $config['updatedAt'] = date('c');
    $config['remoteSources'] = array_values(array_filter(array_merge(
        isset($config['remoteSources']) && is_array($config['remoteSources']) ? $config['remoteSources'] : [],
        [[
            'id' => $resolvedSourceId,
            'url' => $url,
            'path' => $payload['source']['path'] ?? '',
            'importedAt' => $config['updatedAt'],
        ]]
    ), 'is_array'));

    $writeError = mcpWriteJsonFile(PoffConfig::configPath($targetDir), $config);
    if ($writeError !== null) {
        return array_merge([
            'route' => 'import-remote',
        ], mcpRemoteContentError($writeError));
    }

    return [
        'route' => 'import-remote',
        'allowed' => true,
        'saved' => true,
        'sourceId' => $resolvedSourceId,
        'importedCount' => count($importedEntries),
        'config' => PoffConfig::hydrateConfigLayout($config, $targetDir),
    ];
}

function mcpRemotePresentationError(string $message, array $extra = []): array
{
    return $extra + [
        'ok' => false,
        'route' => 'remote-work-presentation',
        'error' => $message,
    ];
}

function mcpRemotePresentationCurrentHost(): string
{
    $host = trim((string) ($_SERVER['HTTP_HOST'] ?? ''));
    if ($host === '') {
        return '';
    }
    $parsed = parse_url('http://' . $host, PHP_URL_HOST);
    return strtolower(is_string($parsed) ? $parsed : '');
}

function mcpRemotePresentationHostAllowed(string $host): bool
{
    $normalized = strtolower(trim($host));
    if ($normalized === '') {
        return false;
    }
    if (!mcpRemoteUrlHostIsPrivate($normalized)) {
        return true;
    }

    return $normalized === mcpRemotePresentationCurrentHost();
}

function mcpRemotePresentationBaseUrl(array $parts): string
{
    $scheme = strtolower((string) ($parts['scheme'] ?? ''));
    $host = (string) ($parts['host'] ?? '');
    $port = isset($parts['port']) ? ':' . (int) $parts['port'] : '';
    $path = (string) ($parts['path'] ?? '/');
    if ($path === '') {
        $path = '/';
    }

    return $scheme . '://' . $host . $port . $path;
}

function mcpRemotePresentationSnapshotUrl(string $sourceUrl): array
{
    $parts = parse_url(trim($sourceUrl));
    if (!is_array($parts)) {
        return ['error' => 'Invalid remote work URL.'];
    }

    $scheme = strtolower((string) ($parts['scheme'] ?? ''));
    $host = strtolower((string) ($parts['host'] ?? ''));
    if (!in_array($scheme, ['http', 'https'], true) || !mcpRemotePresentationHostAllowed($host)) {
        return ['error' => 'Remote work host is not allowed.'];
    }

    $baseUrl = mcpRemotePresentationBaseUrl($parts);
    parse_str((string) ($parts['query'] ?? ''), $query);
    $filePath = trim((string) ($query['file'] ?? ''), "/\\");

    if ($filePath === '') {
        $fragment = trim((string) ($parts['fragment'] ?? ''));
        $slug = str_starts_with($fragment, '/') ? trim(ltrim($fragment, '/'), "/\\") : '';
        if ($slug !== '') {
            $resolveUrl = $baseUrl . '?' . http_build_query([
                'ajax' => 'resolve',
                'slug' => $slug,
            ]);
            $resolvedResponse = mcpRemoteHttpGet($resolveUrl, ['Accept: application/json']);
            if ((int) ($resolvedResponse['status'] ?? 0) < 200 || (int) ($resolvedResponse['status'] ?? 0) >= 300) {
                return ['error' => 'Remote work route could not be resolved.'];
            }
            $resolved = json_decode((string) ($resolvedResponse['body'] ?? ''), true);
            $resolvedIsFile = is_array($resolved)
                && (array_key_exists('isFile', $resolved)
                    ? (bool) $resolved['isFile']
                    : (($resolved['type'] ?? 'file') !== 'folder'));
            if (!is_array($resolved) || empty($resolved['resolved']) || !$resolvedIsFile) {
                return ['error' => 'Remote URL must point to one file work.'];
            }
            $filePath = trim((string) ($resolved['path'] ?? ''), "/\\");
        }
    }

    if ($filePath === '' || str_contains($filePath, '..')) {
        return ['error' => 'Remote URL must contain a file work.'];
    }

    return [
        'url' => $baseUrl . '?' . http_build_query([
            'ajax' => 'snapshot',
            'file' => $filePath,
        ]),
        'path' => $filePath,
    ];
}

function mcpRemotePresentationSanitizeHbs(string $template): string
{
    $sanitized = preg_replace('#<(script|style)\b[^>]*>[\s\S]*?</\1>#i', '', $template) ?? $template;
    $sanitized = preg_replace('/\s+on[a-z]+\s*=\s*("[^"]*"|\'[^\']*\'|[^\s>]+)/i', '', $sanitized) ?? $sanitized;
    $sanitized = preg_replace('/\s+style\s*=\s*("[^"]*"|\'[^\']*\'|[^\s>]+)/i', '', $sanitized) ?? $sanitized;
    $sanitized = preg_replace('/\s+(href|src)\s*=\s*(["\'])\s*javascript:[\s\S]*?\2/i', '', $sanitized) ?? $sanitized;
    return trim($sanitized);
}

function mcpRemotePresentationSafetyIssues(string $css, string $js): array
{
    $issues = [];
    if (preg_match('/@import\b|expression\s*\(|url\s*\(\s*["\']?\s*(?:https?:|\/\/|javascript:)/i', $css) === 1) {
        $issues[] = 'style.css contains external or executable CSS.';
    }
    if (preg_match('/<\/style/i', $css) === 1) {
        $issues[] = 'style.css contains an unsafe closing tag.';
    }
    if (preg_match('/\b(?:fetch|XMLHttpRequest|WebSocket|EventSource|importScripts)\b|navigator\s*\.\s*sendBeacon|document\s*\.\s*cookie|\b(?:localStorage|sessionStorage)\b/i', $js) === 1) {
        $issues[] = 'script.js contains network, cookie, or browser-storage access.';
    }
    if (preg_match('/<\/script/i', $js) === 1) {
        $issues[] = 'script.js contains an unsafe closing tag.';
    }

    return $issues;
}

function mcpRemotePresentationCompatibility(array $local, array $remote): array
{
    $matches = [];
    if ($local['extension'] !== '' && $local['extension'] === $remote['extension']) {
        $matches[] = 'same suffix';
    }
    if ($local['mimeType'] !== '' && $local['mimeType'] === $remote['mimeType']) {
        $matches[] = 'same MIME';
    }
    if ($local['kind'] !== '' && $local['kind'] !== 'other' && $local['kind'] === $remote['kind']) {
        $matches[] = 'same work type';
    }

    return [
        'compatible' => $matches !== [],
        'matches' => array_values(array_unique($matches)),
    ];
}

function mcpRemotePresentationLocalState(string $targetDir, string $targetFile): array
{
    $layoutDir = PoffConfig::fileLayoutDir($targetDir, $targetFile);
    $files = [];
    foreach (['work.hbs', 'style.css', 'script.js'] as $fileName) {
        $path = $layoutDir . DIRECTORY_SEPARATOR . $fileName;
        $files[$fileName] = [
            'exists' => is_file($path),
            'bytes' => is_file($path) ? (int) (filesize($path) ?: 0) : 0,
        ];
    }

    return [
        'directory' => '.works/' . $targetFile . '.layout',
        'hasPresentation' => count(array_filter($files, static fn(array $file): bool => $file['exists'])) > 0,
        'files' => $files,
    ];
}

function mcpRemotePresentationAtomicWrite(string $path, string $content): bool
{
    $dir = dirname($path);
    if (!is_dir($dir) && !mkdir($dir, 0775, true) && !is_dir($dir)) {
        return false;
    }
    try {
        $suffix = bin2hex(random_bytes(5));
    } catch (Throwable) {
        $suffix = str_replace('.', '', uniqid('', true));
    }
    $temporary = $path . '.tmp-' . $suffix;
    if (file_put_contents($temporary, $content, LOCK_EX) === false) {
        return false;
    }
    if (!rename($temporary, $path)) {
        @unlink($temporary);
        return false;
    }

    return true;
}

function mcpRemotePresentationRestoreFiles(array $before): void
{
    foreach ($before as $path => $state) {
        if (!empty($state['exists'])) {
            mcpRemotePresentationAtomicWrite($path, (string) ($state['content'] ?? ''));
        } elseif (is_file($path)) {
            @unlink($path);
        }
    }
}

function mcpRemotePresentationApply(
    string $targetDir,
    string $targetFile,
    array $presentation,
    array $remote,
    bool $confirmReplace
): array {
    $localState = mcpRemotePresentationLocalState($targetDir, $targetFile);
    if ($localState['hasPresentation'] && !$confirmReplace) {
        return mcpRemotePresentationError('Local work presentation exists. Confirm replacement.', [
            'requiresConfirmation' => true,
            'localPresentation' => $localState,
        ]);
    }

    PoffConfig::ensureFileConfig($targetDir, $targetFile);
    $layoutDir = PoffConfig::fileLayoutDir($targetDir, $targetFile);
    $managed = [
        'work.hbs' => (string) $presentation['workHbs'],
        'style.css' => (string) $presentation['styleCss'],
        'script.js' => (string) $presentation['scriptJs'],
    ];
    $before = [];
    foreach (array_keys($managed) as $fileName) {
        $path = $layoutDir . DIRECTORY_SEPARATOR . $fileName;
        $before[$path] = [
            'exists' => is_file($path),
            'content' => is_file($path) ? (string) file_get_contents($path) : '',
        ];
    }
    $wrapperPath = $layoutDir . DIRECTORY_SEPARATOR . 'template.hbs';
    $before[$wrapperPath] = [
        'exists' => is_file($wrapperPath),
        'content' => is_file($wrapperPath) ? (string) file_get_contents($wrapperPath) : '',
    ];

    $backupPath = '';
    if ($localState['hasPresentation']) {
        try {
            $backupSuffix = bin2hex(random_bytes(4));
        } catch (Throwable) {
            $backupSuffix = substr(hash('sha256', uniqid('', true)), 0, 8);
        }
        $backupName = gmdate('Ymd-His') . '-' . $backupSuffix;
        $backupDir = $layoutDir . '.history' . DIRECTORY_SEPARATOR . $backupName;
        foreach ($before as $path => $state) {
            if (!empty($state['exists']) && !mcpRemotePresentationAtomicWrite(
                $backupDir . DIRECTORY_SEPARATOR . basename($path),
                (string) $state['content']
            )) {
                return mcpRemotePresentationError('Could not create presentation backup.');
            }
        }
        $backupPath = '.works/' . $targetFile . '.layout.history/' . $backupName;
    }

    if (!is_file($wrapperPath)) {
        $defaultWrapper = Worktype::layoutBundleAsset(Worktype::defaultLayoutName(), 'template.hbs');
        if (!is_string($defaultWrapper) || trim($defaultWrapper) === '' || !mcpRemotePresentationAtomicWrite($wrapperPath, $defaultWrapper)) {
            mcpRemotePresentationRestoreFiles($before);
            return mcpRemotePresentationError('Could not create local presentation wrapper.');
        }
    }
    foreach ($managed as $fileName => $content) {
        if (!mcpRemotePresentationAtomicWrite($layoutDir . DIRECTORY_SEPARATOR . $fileName, $content)) {
            mcpRemotePresentationRestoreFiles($before);
            return mcpRemotePresentationError('Could not replace complete work presentation.');
        }
    }

    $configPath = PoffConfig::fileConfigPath($targetDir, $targetFile);
    $config = json_decode((string) file_get_contents($configPath), true);
    if (!is_array($config)) {
        mcpRemotePresentationRestoreFiles($before);
        return mcpRemotePresentationError('Could not read local work config.');
    }
    $work = is_array($config['work'] ?? null) ? $config['work'] : [];
    $layout = is_array($work['layout'] ?? null) ? $work['layout'] : [];
    foreach ([
        'template', 'css', 'js', 'sectionTemplate', 'workTemplate', 'worksTemplate',
        'storage', 'directory', 'localDirectory', 'inheritedDirectory', 'sectionDirectory',
        'baseHref', 'sectionBaseHref', 'cssHref', 'jsHref', 'assets', 'files', 'assetCount',
    ] as $legacyKey) {
        unset($layout[$legacyKey]);
    }
    $layout['mode'] = Worktype::filesystemLayoutName();
    $layout['name'] = Worktype::filesystemLayoutName();
    $layout['preset'] = 'custom';
    $work['layout'] = $layout;
    $work['presentationSource'] = [
        'url' => (string) ($remote['url'] ?? ''),
        'title' => (string) ($remote['title'] ?? $remote['path'] ?? 'Remote work'),
        'mimeType' => (string) ($remote['mimeType'] ?? ''),
        'copiedAt' => date('c'),
        'files' => array_keys($managed),
    ];
    $config['work'] = $work;
    $config['updatedAt'] = date('c');
    $writeError = mcpWriteJsonFile($configPath, $config);
    if ($writeError !== null) {
        mcpRemotePresentationRestoreFiles($before);
        return mcpRemotePresentationError($writeError);
    }

    return [
        'ok' => true,
        'route' => 'remote-work-presentation',
        'copied' => true,
        'replaced' => $localState['hasPresentation'],
        'backupPath' => $backupPath,
        'localPresentation' => mcpRemotePresentationLocalState($targetDir, $targetFile),
        'config' => PoffConfig::hydrateConfigLayout($config, $targetDir, $targetFile),
    ];
}

function handleRemoteWorkPresentation(array $opts): array
{
    $rootDir = (string) ($opts['rootDir'] ?? '');
    $input = is_array($opts['input'] ?? null) ? $opts['input'] : mcpReadRequestData();
    $path = trim((string) ($input['path'] ?? ''), "/\\");
    $sourceUrl = trim((string) ($input['url'] ?? ''));
    $action = trim((string) ($input['action'] ?? 'inspect'));
    $access = mcpEditorAccessState($rootDir, $path);
    if (!$access['allowed']) {
        return array_merge(mcpRemotePresentationError('Edit login required.'), $access);
    }
    if ($sourceUrl === '') {
        return mcpRemotePresentationError('Enter a remote work URL.');
    }

    $localFile = mcpResolveFileInsideRoot($rootDir, $path);
    if (!is_string($localFile) || !is_file($localFile)) {
        return mcpRemotePresentationError('Local presentation target must be a file work.');
    }

    $snapshotTarget = mcpRemotePresentationSnapshotUrl($sourceUrl);
    if (isset($snapshotTarget['error'])) {
        return mcpRemotePresentationError((string) $snapshotTarget['error']);
    }
    $response = mcpRemoteHttpGet((string) $snapshotTarget['url'], ['Accept: application/json']);
    $status = (int) ($response['status'] ?? 0);
    $body = (string) ($response['body'] ?? '');
    if ($status < 200 || $status >= 300) {
        return mcpRemotePresentationError('Remote work snapshot is unavailable.');
    }
    if ($body === '' || strlen($body) > MCP_REMOTE_PRESENTATION_MAX_RESPONSE_BYTES) {
        return mcpRemotePresentationError('Remote work snapshot is empty or too large.');
    }

    $snapshot = json_decode($body, true);
    $context = is_array($snapshot['context'] ?? null) ? $snapshot['context'] : [];
    $work = is_array($context['work'] ?? null) ? $context['work'] : [];
    $layout = is_array($work['layout'] ?? null) ? $work['layout'] : [];
    $presentation = [
        'workHbs' => mcpRemotePresentationSanitizeHbs((string) ($layout['sectionTemplate'] ?? $layout['defaultSectionTemplate'] ?? '')),
        'styleCss' => (string) ($layout['css'] ?? ''),
        'scriptJs' => (string) ($layout['js'] ?? ''),
    ];
    if ($presentation['workHbs'] === '' || strlen($presentation['workHbs']) > MCP_REMOTE_PRESENTATION_MAX_HBS_BYTES) {
        return mcpRemotePresentationError('Remote work does not expose a reusable work presentation.');
    }
    if (strlen($presentation['styleCss']) > MCP_REMOTE_PRESENTATION_MAX_ASSET_BYTES || strlen($presentation['scriptJs']) > MCP_REMOTE_PRESENTATION_MAX_ASSET_BYTES) {
        return mcpRemotePresentationError('Remote presentation CSS or JS is too large.');
    }

    $remotePath = trim((string) ($snapshot['meta']['path'] ?? $snapshotTarget['path'] ?? ''), "/\\");
    $remote = [
        'title' => trim((string) ($snapshot['meta']['title'] ?? $context['title'] ?? basename($remotePath))),
        'path' => $remotePath,
        'extension' => strtolower(pathinfo($remotePath, PATHINFO_EXTENSION)),
        'mimeType' => strtolower(trim((string) ($context['mimeType'] ?? ''))),
        'kind' => strtolower(trim((string) ($work['type'] ?? $snapshot['kind'] ?? ''))),
        'url' => $sourceUrl,
    ];
    $local = [
        'path' => $path,
        'extension' => strtolower(pathinfo($localFile, PATHINFO_EXTENSION)),
        'mimeType' => strtolower((string) (MediaType::detectMimeType($localFile, basename($localFile)) ?? '')),
        'kind' => strtolower(MediaType::classifyExtension(basename($localFile))),
    ];
    $compatibility = mcpRemotePresentationCompatibility($local, $remote);
    $safetyIssues = mcpRemotePresentationSafetyIssues($presentation['styleCss'], $presentation['scriptJs']);
    $compatible = $compatibility['compatible'] && $safetyIssues === [];
    $targetDir = dirname($localFile);
    $targetFile = basename($localFile);

    if ($action === 'copy') {
        if (!$compatible) {
            return mcpRemotePresentationError('Remote work presentation is not safe and compatible.', [
                'matches' => $compatibility['matches'],
                'safetyIssues' => $safetyIssues,
            ]);
        }
        return mcpRemotePresentationApply(
            $targetDir,
            $targetFile,
            $presentation,
            $remote,
            (bool) ($input['confirmReplace'] ?? false)
        );
    }
    if ($action !== 'inspect') {
        return mcpRemotePresentationError('Unsupported presentation action.');
    }

    return [
        'ok' => true,
        'route' => 'remote-work-presentation',
        'compatible' => $compatible,
        'matches' => $compatibility['matches'],
        'safetyIssues' => $safetyIssues,
        'local' => $local,
        'remote' => $remote,
        'presentation' => $presentation,
        'presentationBytes' => [
            'work.hbs' => strlen($presentation['workHbs']),
            'style.css' => strlen($presentation['styleCss']),
            'script.js' => strlen($presentation['scriptJs']),
        ],
        'localPresentation' => mcpRemotePresentationLocalState($targetDir, $targetFile),
    ];
}

# PageOff – Oberste Architektur

**Konzeptstand: 20. November 2026**

## Grundidee

PageOff ist ein dezentrales, dateibasiertes Content-Management-System. Jede Installation ist ein eigenständiger Node, der seine Dateien, Works, Metadaten und Layouts selbst verwaltet. Nodes können sich verbinden und bilden einen gerichteten Graphen, keinen zentral verwalteten Verzeichnisbaum.

> Ein Node besitzt seine Ressourcen. Ein Host verwaltet seine Verbindungen. Ein Frontend-Kit bestimmt deren Darstellung.

Es gibt keine verpflichtende zentrale Instanz. `off.page` ist ein Host nach denselben Regeln wie andere Hosts.

## Vier logische Schichten

### Dateisystem und Metadaten

- Normale Dateien und Ordner bleiben die Inhalte.
- `poff.config.json` speichert Ordnerkonfigurationen, Work-Einträge und Einstellungen.
- `.works/` enthält Metadaten einzelner Works.
- Layouts können lokal definiert oder aus übergeordneten Ordnern geerbt werden.
- Eine zentrale Datenbank ist nicht erforderlich.

### PageOff-Core

Der Core verwaltet Works, Ordner, Ressourcen, dauerhafte Work-IDs, ID-zu-Pfad-Auflösung, lokale Parentfolder-Beziehungen, Metadaten, Layout-Vererbung, öffentliche Bereitstellung und grundlegende Zugriffsprüfungen.

Jedes Work hat eine dauerhafte ID, die Umbenennen und Verschieben übersteht. Eine Identität besteht zunächst aus Node-Adresse plus Work-ID. Eine Kopie auf einem anderen Node erhält eine neue ID; `copiedFrom` kann ihre Herkunft festhalten.

### Optionales Host-Modul

Das Host-Modul ist eine optionale Fähigkeit eines Nodes. Es aktiviert bestimmte Ordner als Hosts, nimmt externe Nodes und Works per URL auf, verwaltet direkte Graph-Verbindungen, offene oder kuratierte Einreichungen, Host-Ordnerrechte und öffentliche Informationen zu direkten Verbindungen.

Ein Host kann einen ganzen Node oder einzelne Works verknüpfen. Die Originalressource bleibt beim Ursprungs-Node. Eine Verbindung erstellt weder automatisch eine Dateikopie noch erfordert sie Synchronisation. Der lokale Host-Eintrag liegt im eigenen Parentfolder. Mehrere Hosts können dieselbe externe Ressource in unterschiedlichen Parentfoldern führen.

### Frontend-Kit

Das Frontend-Kit rendert Works, stellt Layouts und Gestaltung bereit, bietet Ordner- und Netzwerknavigation, zeigt externe Ressourcen als normale Works und kann gemountete Nodes durchsuchbar machen. Es kann unerreichbare Ressourcen als offline anzeigen.

Ob ein fremder Node wie ein Ordner durchsuchbar ist oder als Einstiegspunkt erscheint, entscheidet das Frontend-Kit. Core stellt dafür die nötigen öffentlichen Informationen und Zugriffe bereit.

## Node, Host, Work und Verbindung

- **Node:** unabhängige PageOff-Installation mit eigener Adresse und eigenen Ressourcen.
- **Host:** aktivierter Ordner innerhalb einer Installation. Ein Node kann mehrere Hosts betreiben.
- **Work:** identifizierbare lokale oder externe Ressource beziehungsweise ein Eintrag.
- **Parentfolder:** Ordner, der einen Work-Eintrag enthält und dessen lokalen Kontext bestimmt.
- **Verbindung:** lokaler Eintrag, der auf einen externen Node oder ein externes Work verweist.

Ein Host speichert nur direkte Verbindungen; indirekte Verbindungen fremder Nodes werden nicht automatisch übernommen. Mounten erstellt eine Verbindung. Unmounten entfernt diese Verbindung, nicht die Ursprungsressource. Bei Nichterreichbarkeit bleibt die Verbindung bestehen und kann offline angezeigt werden.

## Hosting und Redaktion

Hosting wird für einen Ordner ausdrücklich über eine `host`-Konfiguration in der vorhandenen `poff.config.json` aktiviert. Eine zusätzliche `.allowhost`-Datei ist nicht vorgesehen.

Jeder Host legt die Behandlung von Einreichungen fest:

- **Open:** zulässige Einreichungen werden unmittelbar aufgenommen.
- **Curated:** Einreichungen bleiben bis zur redaktionellen Freigabe verborgen.

Andere Nodes können sich selbst anmelden; Redaktionen können Nodes und Works direkt hinzufügen.

- **Ordnerinhaber:** aktiviert Hosts und vergibt Rechte.
- **Redaktion:** verwaltet Einreichungen und bearbeitet lokale Works im zugewiesenen Bereich.
- **Einreichende:** bieten Ressourcen zur Aufnahme an, sofern der Eingang dies zulässt.

Redaktionsrechte gelten in Unterordnern weiter, bis eine neue Host-Grenze mit eigenen Rechten beginnt. Das Aufnehmen eines fremden Works gewährt keine Bearbeitungsrechte am Original.

## `index.php` und Host-Modul

Logische Module und ausgelieferte PHP-Dateien sind getrennte Entscheidungen. `index.php` bleibt der zentrale Einstieg und stellt Viewer, Editor und Core-Funktionen bereit. Ein Node funktioniert ohne aktivierten Host und stellt öffentliche Works über stabile IDs bereit.

Host-Funktionen werden im Quellcode eigenständig organisiert. Vorläufig bleibt es bei einer ausgelieferten `index.php`; ein zusätzliches `host.php` ist nur sinnvoll, wenn es Auslieferung, Wartung oder Funktionstrennung verbessert. `server.php` ist kein festgelegter Architekturbaustein.

## Netzwerk

Nodes nehmen einander auf, ohne ihre Unabhängigkeit aufzugeben. Jeder Host bestimmt seine Verbindungen, Einreichungen, Rechte und Layouts. `off.page` kann gemeinsamer Einstieg und kuratierter Host sein, hat aber keine Sonderrechte. Netzwerkbereiche können unabhängig erreichbar, zeitweise offline oder neu verbunden sein.

## Stand und offene Punkte

**Bereits vorhanden:** dateibasiertes CMS, Viewer, Editor, Worktypes, Layout-Vererbung, externe Links, Remote-Exporte, lokale Kopien, Node-Anmeldungen sowie grundlegende Einreichungs- und Freigabefunktionen.

**Beschlossen, aber noch nicht vollständig implementiert:** dauerhafte Work-ID-Auflösung, einheitliche Graph-Verbindungen, hostbezogene Redaktionsrechte, klare Host-Grenzen und optionales Host-Modul.

**Noch offen:** Domainwechsel eines Nodes, mögliche dauerhafte Node-IDs, genaues Host-Konfigurationsschema, endgültiger PHP-Dateisplit und Schnittstelle für dynamische Netzwerknavigation.

## Architekturprinzip

PageOff soll als einzelner Node einfach und unabhängig bleiben und durch freiwillige Verbindungen zu einem dezentralen, redaktionell gestaltbaren Netzwerk wachsen. Erweiterbarkeit entsteht durch gemeinsame Ressourcenidentitäten, lokale Parentfolder-Beziehungen und ein optionales Host-Modul – nicht durch eine zentrale Plattform.

# prompt-concator und die Ein-Datei-Auslieferung

## Einschätzung zum npm-Paket

Geprüft wurde `prompt-concator@1.4.2`. Es ist ein Werkzeug, das ausgewählte Dateien per Glob zu einer Textdatei zusammenfügt. Standardziel ist `input-prompt.txt`. Es unterstützt Ausschlussregeln, `.gitignore`, Watch-Modus und TextEdit auf macOS. Damit eignet es sich, einen gezielten Quellcode-Kontext für eine LLM-Frage zu erstellen.

Es ist kein PHP-Bundler. Das Paket löst keine PHP-Imports auf, analysiert keine Namespaces oder Klassen, behandelt dynamische `include`-Aufrufe nicht semantisch und erstellt kein ausführbares, geprüftes Einzeldatei-Artefakt. Die bestehende PHP-Ausgabe entsteht im Projekt bereits mit einem eigenen, geordneten Builder.

Der Watch-Modus synchronisiert Änderungen aus der zusammengesetzten Textdatei zurück in Quelldateien. Wenn die Git-Option aktiv ist, führt der Paketcode `git add .` und anschließend `git commit` aus. Deshalb eignet sich das Werkzeug für eine gezielte, schreibgeschützte Dateiauswahl ohne Watch- oder Git-Modus, wenn es nur als LLM-Kontextsammler dienen soll. Ein pauschales Einschließen des ganzen Projekts kann außerdem vertrauliche oder generierte Dateien in den Prompt übernehmen.

Hinweis bei Verwendung: npm-Metadaten deklarieren Lizenz `ISC`, die mitgelieferte README nennt dagegen „Buy Me a Beer License“. Diesen Widerspruch vor einer Weiterverteilung des Pakets klären. Die Metadaten geben außerdem `node --test` als Tests an, obwohl der npm-Tarball keine Testdateien enthält.

Quelle: [npm prompt-concator](https://www.npmjs.com/package/prompt-concator) · [npm Registry-Metadaten, Version 1.4.2](https://registry.npmjs.org/prompt-concator)

## Bereits vorhandener Build

`build/build.php` erzeugt aus der modularen PHP-Quelle die einzelne PHP-Einstiegsdatei. Es fügt Komponenten in expliziter Reihenfolge zusammen, entfernt PHP-Tags und ausgewählte `require_once`-Zeilen, baut Worktype-Komponenten ein, bettet LightnCandy ein und schreibt die Ausgabe. `BuildConfig.php` und `BuildConfig.shared.json` bestimmen Ausgabe und lokale Verteilungsziele. `ComponentReader.php`, `FileCopier.php` und `PoffConfigBuilder.php` sind Teile der Build-Implementierung.

Asset-Build und Beobachtung laufen zusätzlich über `scripts/build-assets.js` und `scripts/watch-build.js`. Die erzeugten Asset-Dateien bleiben gebaute Ausgaben. `src/includes/header.built.php` und `src/includes/scripts.built.php` sind generiert. Sie sind keine Quellen für eine Implementierungsanalyse.

Die Builder-Logik kennt konkrete Dateireihenfolge, PHP-Tag-Entfernung, Compile-Zeit-Einbettung und Verteilung. Das ist projektspezifische Auslieferung und unterscheidet sich von einer generischen Dateikonkatenation. Das erzeugte Einzeldatei-Artefakt enthält außerdem eingebetteten LightnCandy-PHP-Code. Der ausgelieferte PHP-Code bleibt für den Betreiber lesbar.

### Vorgeschlagene Abnahme für den nächsten Builder-Schritt

1. **Größenbericht beim Zusammenstellen.** Pro Block Herkunft, Kategorie und tatsächlich angehängte Bytes ausgeben. Die zweite CSS-Einbettung separat zählen. Vor und nach dem abschließenden PHP-Strip die Gesamtgröße messen. Development und Production nur aus demselben Quellstand mit den jeweils zugehörigen Assets vergleichen.
2. **Abhängigkeiten prüfen.** Statisch auflösbare Includes samt Einbindungsart erfassen. Für dynamisch geladene Worktypes, eingebettete Templates und ausgeführte Initialisierung die bestehende Reihenfolge und Verarbeitung ausdrücklich beschreiben. Ein unbekannter Pfad bleibt ein offener Befund. Eine Streichung braucht den Nachweis, dass alle unterstützten Wege weiterhin funktionieren.
3. **Kandidaten prüfen.** Den fertigen Inhalt in eine temporäre Datei im Zielverzeichnis schreiben, vollständig geschriebenen Umfang prüfen und `php -l` darauf anwenden. Die bestehende MCP-Suite prüft viele Quellpfade. Für eine künftige Release-Prüfung zusätzlich genau den Kandidaten mit isolierten Testdaten prüfen: Ein Konfigurations-POST speichert und liefert den neuen Wert. Der Aufruf zur Layoutübernahme liefert die erwartete Routenantwort. Hauptseite und Einzelviewer erhalten beide ihre Styles.
4. **Geprüfte Datei übernehmen.** Erst nach erfolgreichen Prüfungen den Kandidaten im selben Dateisystem per `rename` übernehmen. Bei einem Fehler vor der Übernahme bleibt die bisherige Zieldatei verwendbar. Heute schreibt `file_put_contents` direkt ans Ziel. Die aktuelle temporäre Datei dient dem PHP-Strip. Für Kopien an weitere Nodes gilt die atomare Übernahme je Ziel einzeln. Der Watcher führt nach einem erfolgreichen Build eigene Kopierschritte aus und muss denselben geprüften Stand verwenden.
